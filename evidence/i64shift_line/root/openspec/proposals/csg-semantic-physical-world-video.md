# CSG 语义物理世界与动态视频

状态：`propose`，2026-09-06。本轮交付开发计划；世界模型、人物控制与视频引擎尚未实施。现有其他战役的授权与进度不由本提案改变。

## 目标

用 CSG 统一表达语义目标、世界状态、物理规律、控制过程、渲染计算与资源引用，由 Cheng 执行，生成具有连续人物运动、可修改动作及一致机位的剧情视频。

首个功能交付：同一角色在岩壁上连续攀绳 10 秒；完成交替抓握、蹬踏与抬升；从同一检查点取消全部支撑后按定义的物理规则下落；同一模拟记录输出三个机位。最终交付扩展为 60–90 秒、6–10 个镜头的原创出山短片，角色造型、表情、灯光、对白和声音完整。

## 固定边界

- 首期平台为本地 macOS arm64。纯 Cheng CPU 离线渲染是正式首期执行器；输出为 1280×720、24 fps，不承诺实时生成。GPU 加速在独立阶段完成真实编译与执行接线后启用。
- 自有语义、资产加工、控制、物理、渲染、混音和封装逻辑使用 Cheng；允许明确列账的系统文件、线程、驱动及硬件媒体接口。首期拟用系统 H.264/AAC 编码接口编码 Cheng 生成的画面和混音，Cheng 管理时间戳与容器封装；不声称系统编码算法也是 Cheng。
- 不调用收费平台，不把 Python、Blender、远端生成 API 或内嵌外语算法作为生产执行器。模型权重、网格、纹理、录音属于有类型与 CID 的数据资源。
- 沿用唯一 `src/game` ECS、运行时和资源体系；通用规范以 `docs/csg-core-standard.md`、语言以 `docs/cheng-formal-spec.md` 为准。世界域是拟新增扩展，producer、精确 validator、consumer 接线前不得登记为已支持。
- 语义成功必须由物理状态与过程条件验证。控制器输出目标和力/力矩；世界位置由求解器推进，禁止用预写轨迹覆盖结果。
- 所有运行引用使用带实例与代际校验的精确整数索引，内部 DOD + Arena + SoA；公开使用值与 `var T` 隐式借用。不得以名称、位置相近或裸指针匹配人物和骨架。
