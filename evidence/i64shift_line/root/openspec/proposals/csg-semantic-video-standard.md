# CSG语义视频标准与统一消费

日期：2026年9月16日。状态：apply（实施中）。同日文档交付完成；B1 格式层+独立 Cheng 解码器互操作对拍完成；B2 结构语义转换（真实存量两样例闭环）、B3 语义播放器（验证/查询/seek/证据回溯）、E1-lite 计量层（冷包/热传输/恢复单元实测报告）已完成；对象级语义待识别模型接线，像素播放待解码桥，C1 实采未开始。f 闭环 S1-S4 已过门（快照块/恢复对拍/公平压缩基准/统一消费入口），S5 探测确认实拍提取阻塞于解码桥像素出口。

## 问题与目标

现有存量转换、端上采集和场景播放实验使用不同表示和验证口径，尚未形成统一的语义、状态恢复及实时修订合同。拟以CSG共同核心连接文件转换、原生拍摄和直播，并使AI查询、音画播放及声明范围内的世界执行消费同一版本内容。

## 标准定义与规范边界

**CSG语义视频**：以内容寻址语义图将源音画观测、时空实体、语义断言、版本化状态及其依赖绑定，使消费者针对同一已提交版本进行证据查询、音画呈现，并在明确声明和验证的能力范围内恢复空间或执行世界状态的媒体表示。CSG在此不是构造实体几何；标准不要求所有对象使用几何布尔表示。

存量视频转换为主线，原生拍摄和直播产生同构记录。像素媒体可作为类型化观测资源保留；仅封装视频或附加文字摘要不等于语义描述合规。单目视频不能唯一确定的尺度、遮挡区域和物理参数必须保留未知或标记推断，不自动取得世界执行资格。

本提案定义范围与验收义务；[核心技术方案](../../docs/csg-semantic-video-core-design.md)定义消费行为；[v0.1领域schema](../../docs/specs/csg-semantic-video-v0.1.md)是当前冻结字段与字节合同。下表不是新增字段，也不声称冻结schema已经充分编码或实现全部行为。超出v0.1表达能力的内容，必须先提出版本化扩展并验证互通，不能塞进可忽略扩展后宣布支持。

| 编号 | 规范义务 | 合规判据 |
|---|---|---|
| SV-01 观测落地 | 语义绑定精确源轨道、样本区间、区域、时基和标定；区分观测、推断、人工与未知 | 查询能定位依据；识别未完成不解释为对象不存在 |
| SV-02 身份与修订 | 实体身份与内容、分支、状态版本分开；解释修订追加，不改写拍摄历史 | 同名实体不串接；旧解释与当前解释可分别重建 |
| SV-03 能力合同 | 共同核心、语义描述、空间重建、世界执行、实时传送分别声明和验证 | 请求能力缺失明确失败，不以格式PASS替代功能PASS |
| SV-04 恢复闭包 | 跳播与直播加入取得精确基态、必需资源、解码参考及执行历史 | 缺依赖、基态冲突、非法循环时不提交状态，不以占位画面记首帧 |
| SV-05 补偿隔离 | 观测补偿绑定取样、源版本、执行描述及完整输入域，只写表现输出 | 交互或修订后重验；新增遮挡、空查询域变化能使旧补偿失效；不得写回物理状态 |
| SV-06 同版本消费 | 查询、呈现和操作读取同一提交；操作核对对象、前状态及权限 | 版本冲突拒绝；回执绑定实际处理，不以请求发送代替完成 |
| SV-07 流式时序 | 保留源时钟、流世代、连续提交、缺口和迟到修订；有限队列事件驱动 | 重启不续接旧增量链；乱序、断流、超时与正常结束可区分 |
| SV-08 性能与互通 | 独立实现互通；完整依赖体积、缓存增量、转换、发布及首帧分别测量 | 同质量同能力比较；冷端资源真正可取回且真实上屏；千倍压缩、秒发秒开不得由局部数据外推 |

共同核心包含观测、实体、语义断言、状态快照/增量、观测补偿、依赖、修订和回执。复用CSGC、唯一根与证明、资产系统、世界运行时及播放器，不新建事实codec或生产信任入口。自有生产语义使用Cheng；独立实现可使用其他语言。系统采集、编解码、模型和硬件能力独立列账。

内容哈希证明所绑定字节的一致性，不证明现实真实性、识别正确、行为授权或第三方专利许可。必要质量未达标即失败，不能因旧补偿被排除而把不合格的新画面标成同质量成功。
