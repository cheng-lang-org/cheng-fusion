# 纯 Cheng CSG 资产管线

状态：`propose`，2026-09-06。本轮制定开发计划，未实施导入器。作为 [CSG 世界视频提案](csg-semantic-physical-world-video.md) 的资产子项目，细化其 D1，复用同一资产身份、CSGC 格式、验证与运行时。

## 目标与交付

将存量媒体、Blender/UE 导出的受支持资产、后续 USD 场景转换为可验证、可复用的 CSG 资产。声明的能力必须由真实消费者验证：媒体可播放，网格可展示，动画可求值，物理规则可被干预。未知语义、源导出遗漏和资源损坏不能变成默认值或成功回执。

首个完整资产交付：一段原视频保真入库；一个 Blender 静态场景和骨骼角色、一个 UE 静态场景和骨骼角色，经 GLB 导入后由 Cheng 加载、实际绘制与播放；绑定来源和导入回执。物理交互和完整源工程等价分别在后续阶段验收。

## 边界

- 自有导入、验证、规范化、资产加工、加载、依赖计算及执行代码为 Cheng。源应用的官方离线导出是创作边界，不进入发布后的加载/执行闭包；不新增自有 Python/C++ 适配器或链接 Assimp/OpenUSD 承载语义。
- 首期输入为完整本地媒体文件和受支持 GLB。直接解析 `.blend/.uasset`、任意蓝图/节点、任意 USD 插件或原工程语义是单独的源格式工作，不能算在 GLB 导入完成中。
- 通用事实复用 CSG core 资源机制；三维/行为使用世界计划拟定的 world 扩展，实际接线前不注册。`oracle_asset` 不用于三维素材。输出是现有 CSGC＋按 CID 绑定的资源字节，不另建资产 wire 或数据库权威。
- 原始字节、源对象身份、资产版本、实例身份、观察结果与重建假设分别记录。原视频不会因封签就成为可干预三维世界，动画缓存不会自动变成物理控制器。
- 不使用付费平台、不上传或下载大批资产。后续实现先冻结具体样例、源软件版本和资源预算。
