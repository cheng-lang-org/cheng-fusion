## 一、本轮要什么

**现在只融一笔：人民币 150 万元，12 个月，验证「碰一下，内容到对面手机」。**

买的不是工厂，是四个可证伪的数：15 秒片子、按键到 Android 可见、20 块板借出去有没有人再发、有没有人问成品在哪买。四个数过了，才单独谈 **400 万元量产预备轮**（认证、开模、500 套 NPI）。两笔捆成「种子 550 万已经含工厂」，本计划作废。

| | 验证轮（现在） | 量产预备轮（以后） |
|---|---|---|
| 金额 | **150 万** | **400 万** |
| 主体 | 境内承道合一 | 另签；境内试产 + 新加坡 HoldCo 接海外许可 |
| 覆盖 | P0–P6 | 仅 P7 |
| 期限 | 12 个月 | 漏斗第 4 项成立后 12 个月 |
| 现在能否签约 | 能 | 不能写进本轮条款 |

钱怎么分两档拨：

1. **签约即拨 40 万**：买板、夹具、拍 P0 片子。90 天内交不出「未讲解路人能复述产品干什么」的片子，剩余 110 万不拨，已花费按票据核销。
2. **P0 过关再拨 110 万**：门禁数字、20 块外借、Cheng 固件、功耗曲线。开模、SMT、广告、众筹、渠道进场费一律禁止。

Cheng 热路径、UniMaker 公测、零 C 走软件主轮，不从这 150 万里抽。

## 二、一句话

口袋信物是 UniMaker 的物理发布键。人摇一下、点一下、两块板对碰，短语音进 UniMaker，对面手机秒开，板上震动回执。

不卖语音助手，不卖端侧大模型，不卖开发板换壳。软件已经在 Android 真机上测过「发布到可见」；硬件用乐鑫现成的 ESP-Mosaico，把发布变成一个物件动作。硬件获客，软件留存和收费。

---

## 三、为什么现在值 150 万

现场想丢一句给对面，今天仍要打开 App、选相册、等上传。对讲机太专用，社交 App 太重。AI 徽章把命运绑在云端模型上，模型挂了产品就死。

口袋信物只保证三件事：动作确定、回执确定、内容在 UniMaker 里打开。模型挂了，录、存、震还在。

150 万够不够：够把评估板上的闭环拍出来，不够开工厂。这是刻意的。评估板没有 CE / UL / CCC，乐鑫第 5 章写明不是消费品。先验证动作，再花钱认证。

## 四、15 秒验收（P0，本轮第一笔钱的交付）

1. 方屏亮出本人信物印。
2. 按功能键或摇一下，录短语音，屏上出波形。
3. 松手即发，旁边手机 UniMaker 弹出同一条。
4. 板子震动，表示对面已打开。

第二部手机拍这 15 秒，就是获客素材。做不到，后面的商业模式不成立，110 万不拨。

## 五、已验证 / 未验证

投资人买的是左边；右边是本轮要关掉的缺口。

| 已验证 | 本轮结束前必须补上 | 本轮结束后仍没有、不准对外说 |
|---|---|---|
| Cheng 自举不动点 `e202c0c35424eb36`，`ci_gate` 35/35 | 15 秒片子 | 把评估板当商品零售 |
| Android hash 命中 0 ms；特定视频资产端到端 944 ms | 按键到 Android 可见的硬件报告（同一门禁字段，不沿用 944 ms） | 续航小时数、太阳能续航 |

| | 三条电流曲线 | TAM、毛利、回本月数 |

演示词只允许：「内容走 Cheng / UniMaker 发布链；V0 板端采集用乐鑫 BSP。」

## 六、为什么是这块板，不是别的 ESP32-S31

乐鑫分册三块板，只有 Mosaico 长得像物件。

| 板 | 形态 | 本计划 |
|---|---|---|
| ESP-Mosaico V1.0 | 方屏、麦喇叭、六轴、双磁力计、震动、左右磁吸槽、65 mAh | **唯一载体** |
| Korvo-1 | 双麦、摄像头、4.3 寸屏 | 实体秒发机另案 |
| Function-CoreBoard-1 | 千兆网、无屏 | 不当消费品 |

三件别人不好抄的开箱能力：双 BMM150 看磁场梯度（哪边贴着、两板对碰）；480×480 方屏只当印；左右槽带 EEPROM，V1 加摄像头和大电芯不用改主板。

板载没有 NFC。近场用蓝牙换 DID，磁只用到「碰上了」。太阳能只许 5V 板插着补电，养不活亮屏 Wi-Fi。

## 八、怎么赚钱

语言开源，钱收在 UniMaker 和以后的自有硬件。转卖乐鑫评估板不是生意，也不做众筹。

| 阶段 | 收 | 不收 |
|---|---|---|
| 验证期 | 不收费。只看会不会每天用一次 | 评估板加价、创始人编号 |
| 公测 | UniMaker 付费层：额度、信物主题、多设备 | 硬件保证金当主营 |
| V1 | 自有 SKU 毛利 + 订阅。一板一设备身份 | 模块抽成活命 |
| 企业 | 活动「碰一下签到」，走 UniMaker 企业层 | 改协议的定制中枢 |

定价等功耗曲线、小批量 BOM、订阅转化齐了再写。现在写价格是表演。

投资人看的四个漏斗（量产轮的钥匙）：

1. 未讲解的人能否说出片子里的产品。
2. 20 块借板，7 天内多少人自发再发。
3. 其中多少条对面真的打开了。
4. 多少人问「成品在哪买」。

第 4 项为零，400 万不开。

## 十、融资计划

### 10.1 交易结构

验证轮进入**境内承道合一**，口袋信物单独核算，不和 RWA、具身混账。开源 steward（新加坡 CLG）不持股、不收这笔钱。开曼基金不参与本轮。评估板库存不算境外资产。

建议工具：**股东借款 + 转股选择权（可转债）**，期限 18 个月。

- 转股触发：P0 片子验收，或下一轮合格融资（量产预备轮或软件主轮，先发生者），孰早。
- 转股价格：下一轮单价的 **80%**。18 个月内无下一轮，按签约时约定的上限转股，上限在条款里谈，**本计划不预设投后估值**。
- 也可改为直接增资。无论哪种，开模、众筹、把评估板公开零售，投资人有一票否决。

本轮不锁定「占股百分之几」。片子出来之前谈死估值，是用没发生的故事定价。

### 10.2 150 万怎么花

### 10.3 投资人权利（建议写进条款）

1. **信息权**：每月里程碑一页，P0 / P1 / P5 原件（片子、门禁报告、电流曲线）。
2. **否决**：开模、众筹、评估板零售、把本轮资金并入软件工资。
3. **跟投**：量产预备轮按本轮出资占比优先认购。
4. **专项清算优先**：若 18 个月无转股也无下一轮，剩余现金按专项退回，已花费不要求创始人个人回补。
5. **不要求**：不要求进 steward、不要求开源停更、不要求把编译器源码主库迁出境内。

## 附录 A · 硬件约束（乐鑫原文级，产品不得违反）

结构：CoreBoard + BaseBoard，60 针 0.5 mm 板对板。主控 ESP32-S31NRV16，RISC-V 双核最高 320 MHz，封装内 16 MB PSRAM；Wi-Fi 6、蓝牙 5.4、IEEE 802.15.4。屏 CO5300 480×480 QSPI AMOLED + CST9220。音频 ES8311 + NS4150B + 麦。BMI270（0x69）。BMM150×2（0x11 / 0x12）。震动 GPIO8。功能键 GPIO7。16 MB NOR + 1 Gbit NAND。电芯 3.7 V / 65 mAh，充电额定 65 mA（TP4057），电量计 BQ27220（0x55）。

右槽五个脚与板载 I2S 复用（GPIO49/52/54/37/40），占用则放弃板载麦喇叭。左槽摄像头会把 GPIO14 改成 DVP D4，EEPROM 发现暂停。V0 两槽都不插。

乐鑫第 5 章：开发板不是量产组件，不是消费品，无 CE / UL / CCC，无 RMA / PCN / EOL。第一年不得零售评估板。

磁场：双 BMM150 看梯度，不携带身份。碰上之后用蓝牙换 DID。地铁、喇叭、马达、包里晃都会误触发。

太阳能：1–2 W USB 5V 板可以灌这颗电池；亮屏 Wi-Fi 电流大于充电电流，摘线不能逛街。V1 要太阳能必须换大电芯和功率路径充电芯片。
