# 求解器决策（A2）

日期：2026-09-06。状态：冻结（阈值见 [csg-world-contract](../../../docs/csg-world-contract.md)）。

## 方程

1. **积分**（步内恒力精确 + 约束后投影，固定顺序）：
   - `v_i ← v_i + (F_i/m_i)·dt`，`x_i ← x_i + v_i·dt + (F_i/m_i)·dt²/2`。
   - 恒力（重力/常值控制器力）下弹道相为解析精确（探针实测：纯半隐式欧拉 40.9mm > 1cm 预算，本式机器精度）；约束冲量随后位置投影，不回归欧拉误差。
   - 外力仅重力 + 控制器记录力 + 接触/约束冲量；每步力来源写入回执 trace。
2. **绳索**（8-10 质点距离链，段长 L）：
   - 每步对每段做 XPBD 位置投影：`d = |x_j − x_i|`，`Δ = (d − L)/d`，
     `x_i += Δ·(m_j/(m_i+m_j))·(x_j−x_i)`，`x_j −= Δ·(m_i/(m_i+m_j))·(x_j−x_i)`。
   - 32 次迭代/步（实测：8 次迭代下 70kg 负载的 10 节链稳态伸长 >5mm；32 次降至 ~2.2mm ≈ 0.4% 应变，符合真实绳弹性）。
   - 锚点/被抓端逆质量为 0（无穷重）。不收敛判据：单步末端残差 `|d−L| > 10mm`（发散守卫；弹性平衡伸长不算失败）。
3. **接触**（脚/手球 vs 静态平面与 AABB 面）：
   - 穿透 `p > 0` 时位置外推 `x += n·p`，法向速度 `v_n ← max(v_n, 0)`（e=0），
     切向 `|v_t|` 削减 `min(1, μ·|v_n_impulse|/|v_t|)`。
   - 支持组合（其余硬失败）：sphere-plane、sphere-AABB(face)、point-plane。
4. **角色**：质点组（骨盆/胸/头/双手/双脚，7 质点 + 姿态由对应表推出），关节为距离约束（同绳索算子），控制器为有限力（上限 1500N，来源=动作名）。

## 失败条件

- NaN/Inf、残差超限、质量 ≤0、非支持接触组合 → 该步拒绝提交，物理不推进，记 `step_rejected` 事件。禁止静默冻结后导出成功影片。

## 解析验证案例（C1 门）

| 案例 | 期望 | 阈值 |
|---|---|---|
| 自由落体 2.0s | `z(t)=z0+v0t−gt²/2` | 峰值误差 ≤1cm |
| 单摆小角（绳约束, 10°） | 周期 `2π√(L/g)` ±5% | 能量漂移有界 |

## 执行器（C2 冻结）

有上限、有来源的力（合同 §5），不移动约束目标（实测：移动目标会与迭代求解器形成赛跑棘轮，残差单调增长）：

- **拉臂**（armPull）：窗口内对抓握手施加沿手→节点方向的力，上限 1200N；手-节点距离 ≤ minLen（0.10m）时停止。
- **蹬腿**（legPush）：窗口内对骨盆施加沿脚→骨盆方向的力、对脚施加等大反作用力（牛顿第三定律，脚被压向墙面由摩擦锁住），上限 1500N；腿距 ≥ maxLen（0.95m）时停止。
