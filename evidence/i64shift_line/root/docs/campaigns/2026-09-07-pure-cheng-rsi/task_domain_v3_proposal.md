# 任务域 v3 立项提案——第二算法族任务域（确定性数论域）

状态：`propose`（批次六任务 2 立项交付；实现与否由批次六验收口径裁定）。

## 目标

为 RSI 框架扩展第二算法族任务域：**确定性数论域**（GCD/LCM 计算族），
使变更空间从「排序 18 格 + 逆序对 4 格」扩展为三域（+数论 6 格 = 28 格），
在幽灵墙清后提供纯载具全链 A/B 的完整变更空间，并检验白盒观测表模型
在跨域任务上的迁移能力（域间无共享代码路径 = 迁移能力的真检验）。

## 域定义（草案）

- **输入**：三变体确定性数对序列（与既有语料口径一致：LCG 派生，
  (a,b) 对 ×(64,128,32) 三规模，mod 9973/4999/7919）。
- **任务**：逐对计算 GCD（辗转相除族）并输出三变体 GCD 序列的
  sha256（值敏感语义锚：空输出指纹缺陷的教训直接继承——锚必须绑定
  计算值）。
- **策略族（6 格 → 精简 4 格）**：
  - 族 0 朴素递归 GCD（基线，栈深风险对照）
  - 族 1 迭代辗转相除（主竞争者）
  - 族 2 Stein 二进制 GCD（移位实现，无除法路径）
  - 族 3 扩展欧几里得（带系数计算，计算量上限对照）
- **分数**：比较/取模操作计数（与排序域 compares 同构，越小越好）；
- **金标**：独立实现（朴素数学定义直算），与四族程序五路互证
  （数学唯一性：GCD 值唯一 → 指纹必须一致）。

## 准入与评价合同（沿用不变量）

- 语义锚 = 产物运行 rc+stdout sha（值敏感，继承批次四教训）；
- 聚合分 = 跨域账本分之和（排序 + 逆序对 + 数论三域）；
- 白名单：`RsiDomain2StrategyMax = 3, RsiDomain2ParamMax = 0`（6 格）；
- M 规则白盒模型扩展：观测表 cell 布局 = d*6+s（域 2 占 cell 12..15）。

## 前置依赖

  新域候选程序的纯载具编译验证依赖该墙清；

  载具完成 A/B 入图（与批次四/五口径一致）。

## 验收口径

金标五路互证 + 域 2 全格 A/B 入图（accept 或如实拒收）+ gate 腿覆盖
+ verify 三账本绿。
