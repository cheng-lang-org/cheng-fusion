# 任务域 v4 立项提案——三任务域变更空间扩展（generator 下一代）

状态：`propose`（批次八前半立项；按「先提案后动手」流程，实现与否由批次八验收口径裁定）。

## 1. 动机（第一性）

三任务域 26 格已 EXHAUSTED 且在位最优可证（批次七终态：covered=26/26，
incumbent==best_correct；生产账本 v3 epoch 同判）。变更空间不扩，
R4 严格降分合同下系统必然停在空间最优——继续提升的唯一路 = 扩大变更空间。

批次三教训是本提案的硬约束：**分数无差的格在严格准入下永不可达（死格）**。
因此每个新格必须给出「与全空间既有格及新格彼此之间的可观测分数可分」论证，
禁止为凑格数添加 param 不改变输出的格子。

## 2. 扩展设计（+5 格，26 → 31）

### 2.1 域 0 新族：strategy 6 = 快速排序（参数敏感变体）

- 实现：显式栈迭代 Lomuto 快排（`std/seqs.setLen` 弹栈，无递归——不赌
  codegen 递归路径）；`sortInPlace` 签名与既有六族一致，复用既有壳。
- **param = 基准选取档**（真实改变比较次数，非装饰参数）：
  - 档 0：首元素基准（分区前交换 a[lo]↔a[hi]）；
  - 档 1：尾元素基准（Lomuto 经典，无预交换）；
  - 档 2：三数取中基准（2–3 次比较的中位数网络，中位下标交换至 hi）。
- 新格：`(0,6,0) (0,6,1) (0,6,2)`；`RsiDomain0StrategyMax 5→6`；
  域 0 = 7 族 × 3 档 = 21 格。
- 快排与 med3 网络的比较全部计入 outCompares（含基准选取的 2–3 次）。

### 2.2 域 1 新族：strategy 4 = 分块计数·宽 4

- 既有族 3 = 分块宽 8 的结构变体：块内插入计数 + 跨块双重循环，块宽 4。
- 新格：`(1,4,0)`；`RsiDomain1StrategyMax 3→4`；域 1 = 5 格。
- ops 口径与族 3 一致（比较次数），无单位漂移。

### 2.3 域 3 新族：strategy 4 = 扩展欧几里得

- 迭代 Bézout 系数版辗转相除（old_r/r、old_s/s、old_t/t 三行滚动），
  输出 gcd 序列与四族完全同源（r 序列与迭代欧几里得逐步相同）。
- ops 口径 = 每迭代计 7 次系数运算（商 1 + 三行更新各 2）。
- 新格：`(3,4,0)`；`RsiDomain3StrategyMax 3→4`；域 3 = 5 格。

## 3. 分数可分性论证（每格）

已知 26 旧格实测分（批次七回执，真实编译运行）：
- 域 0：冒泡 10640 / 插入 5935 / 选择 10640 / 希尔 2636、3462、5662 /
  堆 2189 / 归并 1127；
- 域 1：朴素 10640 / 归并 1127 / 冒泡 19609 / 分块宽8 10436；
- 域 3：朴素试除 512067 / 迭代欧几里得 1683 / Stein 5402 / 单遍欧几里得 1683。

| 格 | 可分性论证 |
|---|---|
| (0,6,0) | Lomuto 总比较数 = 分区树各子问题 (size−1) 之和，由基准序列唯一决定；首元素基准在固定 LCG 数据上的分区序列与其余两档及既有七族结构不同源。 |
| (0,6,1) | 同上，尾元素基准；三档基准选取函数两两不同 → 分区序列两两不同 → 计数两两不同（数据固定，计数确定）。 |
| (0,6,2) | 同上，三数取中；且每分区额外计 2–3 次基准比较，系统性地偏离零预检档位。 |
| (1,4,0) | 跨块对数公式 C(n,2)−B·C(w,2) 在三变体上与宽 8 差 +448（64 元素：1920 vs 1792；128：7936 vs 7680；32：448 vs 384）；块内插入比较数亦随块宽变化 → 与宽 8 的 10436 可分；与朴素（恒 n(n−1)/2=10640）、冒泡、归并不同源。 |
| (3,4,0) | r 序列与迭代欧几里得逐步相同 → 迭代总数恰等于其 ops=1683；本族 ops = 7×迭代数 = 11781，与 {512067, 1683, 5402} 数值可证不等。 |

**实证闭环**：论证给出「结构性不同源」；实现阶段以真实编译运行核对新格
实测分两两不等且不在 26 旧格分值集内（若撞并列，调整基准档定义并重核——
自由度在档位设计，不在分数捏造）。实测值固化进批次八回执。

## 4. 金标（值敏感，零改动继承）

三域金标不动：域 0 = 计数排序序列哈希、域 1 = 朴素 O(n²) 逆序对数哈希、
域 3 = 朴素减法辗转 gcd 和哈希。新格程序 echo 同一数学量的 sha256
（排序序列 / 逆序对总数 / gcd 值和），评价器对照域金标逐字符裁决——
静默错译（排序错/计数错/gcd 错）直接 wrong_answer，不靠候选自报。
金标与候选族不同源的关系对三个新族依旧成立（快排≠计数排序、宽 4 分块≠
朴素直算、扩展欧几里得≠减法辗转）。
