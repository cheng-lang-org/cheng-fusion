# 复核与权利要求支持

## 算法复核

独立代理与主线程共同复核后完成以下修改：

一、检查点的执行“相容”改为形成过程的实现闭包、状态schema及数值配置精确一致，不允许未经证明的跨实现复用。

二、将操作顺序明确为先检查完整输入和缓存，再于未命中时发现新关系并求解；不能先执行完整求解再声称通过缓存节省该计算。

三、完整耦合域的必要条件进入权利要求1，覆盖能够经接触、约束或共享控制交换影响的全部对象，不能依赖未证明的对象隔离。

四、统一第 n 步为 `S[n-1]` 到 `S[n]`；第3步读取第5步输入时，完成第2步的检查点为该模型中的有效起点。

修订后独立算法复核通过。合成参考实现经主线程阅读及再次运行，15项案例通过；输出完整性依赖可信记录的边界、替代实现标签测试的局限均已写入正文。

## 现有技术及保护范围复核

现有技术代理复核确认主稿没有把dirty传播、拓扑调度和回滚本身写成原创，正确区分相关说明书和独立权利要求。补充了Adapton与自调整计算文献，明确读取轨迹和全量一致性也已有研究。

保护结构由全部多媒体阶段必需改为：权利要求1保护候选状态复用方法，权利要求8增加音画，权利要求13增加共同清单。修改旨在减少无声内容或单独状态服务带来的非必要限定，不说明较宽范围已具备新颖性或创造性。通用增量读取验证、数据库范围和不存在性依赖仍是代理师进一步检索的重点。

第一性原理分析：在没有对象隔离证明时，完整耦合域提供更小的证明负担；先取得可证明的时间与阶段复用，再研究空间细分。为追求“最小重算”而引入旧接触图剪枝会丢掉新增关系，不能采用。
