# B1 逐相内存预算（唯一约束卡映射）

日期：2026年9月16日。约束依据：`docs/campaigns/2026-08-31-kernel-userpath/design/memory_model_constraints.md`（768MiB 总峰、逐相贴线、rc=0 三判据；读数只做同窗口相对比较）。

## 本批（B1）新增结构与影响

| 相 | 新增项 | 工作集上界 | 生命周期与验证 |
|---|---|---|---|
| 读取/解码 | 无生产改动（B1 未接线媒体 demux） | 0 | — |
| 识别/重建 | 无（模型未接线，明确阻塞） | 0 | — |
| 编码/封包（B1 writer，仅测试进程） | 记录行 `str[]` + token 行 + CSGC 输出字节 | 行总长 ≤ 64MiB（v0.1 块上限，`docs/specs/csg-semantic-video-v0.1.md` §1）；测试夹具 ≤ 1MiB 实测占用量级 | encode 完成即释放中间 token 行（复用 `csgcEncodeFromOrdered` 既有释放路径）；无跨任务缓存 |
| 网络/验证 | 无 | 0 | — |
| 恢复/呈现 | 无 | 0 | — |

- B1 全部 4 模块 + 测试为新增文件，共享源码零修改；生产运行时各相结构增量为 0，本表不是生产实测结论。
- 测试进程（smoke）内存按核心 JSON 输入上限（64MiB）自然封顶；实际夹具 KB 量级，逐用例断言后退出，退出码 0。
- 后续 B2 接入真实 demux 时，须把"有界输入窗、codec 状态、已解码帧池"映射进读取/解码相并补系数、计数与同窗口实测；本表届时更新，不得沿用 0 占位。

## 未钉模型项

资源块流式读取的窗口系数（媒体段→内存窗倍数）待 B2 实测钉定；识别相权重/激活项待模型闭包冻结后钉定。两项在钉定前不得以估计值计入达标。
