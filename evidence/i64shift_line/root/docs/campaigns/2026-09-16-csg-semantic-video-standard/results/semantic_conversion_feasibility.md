# 实拍视频→CSG 语义表示：可行性评估（degraded 路线盘点）

日期：2026-09-19。执行：子代理 H3（只读调查，无代码改动）。
问题：在不做研究突破的前提下，「完成实拍视频的 CSG 语义化」能兑现到哪一档。
结论先行：**partially-feasible**——平面级 degraded 语义（结构语义+深度序列+平面场景图+前景残差流）今日即可用，全链证据齐备、无需任何研究突破；对象级完整语义（类别+实例轨迹+属性+关系）**blocked**，精确阻塞点是识别/分割/跟踪模型集成与纯 Cheng 像素字节出口，**不是**「生成式重建」研究门。

## 0. 先拆掉一个混淆：语义提取 ≠ 生成式重建

「实拍视频→CSG 语义表示」和路径 2 的「实拍+生成式重建」是两个需求：

- **语义提取**（识别场景里有什么、在哪、怎么动）：输入像素，输出结构化语义。不需要神经渲染。
- **生成式重建**（把实拍内容重建成可自由视角编辑的 CSG 几何）：需要神经渲染，F5 定谳未解，是真研究门。

本评估对象是前者。把阻塞点笼统归因于「生成式重建未解」会错杀已可用的 degraded 路线。

## 1. 语义提取的四级阶梯与现状

| 级 | 内容 | 状态 | 证据 |
|---|---|---|---|
| L0 | 结构语义：轨级实体、时间索引、样本证据锚、查询回源字节 | **纯 Cheng 生产闭环** | B2/B3（results/b2_convert.md、b3_player.md）：hgs 实测 675 样本/7 观测/2 实体，ffprobe 对照一致 |
| L1 | 量化深度序列（2fps，MiDaS_small @256） | **三端可用** | PC 离线产线（RECEIPT_huguangsheng_stream.md，45 帧→SSM1+DPD1 2.9MB）；Android 端上（task_m16a）；OHOS 端上 mp4→CSGD（task_m16b，对拍 pearson 0.9137）；纯 Cheng 单帧 64×64 corr=0.99997（RECEIPT_midas_full_cheng.md） |
| L2 | 平面级场景结构：RANSAC 平面（带跨帧 tid）、参数轨迹、z 序、MES1 事件化、前景残差流 | **PC 离线工具闭环** | M8a/M9a/M9b/M9c/M10/M11（tools/csg_plane_track.py、csg_fg_stream_pack.py、csg_temporal_depth.py） |
| L3 | 对象级语义：语义类别、实例分割、实例轨迹、属性、关系 | **blocked** | F5 探测（results/f5_extraction_probe.md）：朴素启发式不稳；本树无分割/识别模型链 |

注意 L2 的「对象」是**几何平面**，不是语义对象：一面墙上的海报与墙同平面，同深度带的两个物体会并成一平面。但它已具备退化语义的关键三件套——跨帧身份（tid）、逐帧属性（平面参数 FP16 Δ、zOrder、inlier 份额）、拓扑事件（Born/Death/Mutate）。这就是「对象轨迹+属性」的平面级替身。

## 2. 各 degraded 提取的价值与局限（逐项）

### 2a. L0 结构语义（已有，纯 Cheng）

- 价值：任何实拍 MP4 可转为 svblock 语义记录（实体=轨、观测=关键帧+音频），查询可回源样本字节，B3 播放器可按时间轴消费并出示证据锚。这是「语义化」的合同底座，四级都跑在它上面。
- 局限：实体粒度是**媒体轨**不是画面内对象；无像素内容理解。
- 边界：像素级呈现待 H.264 解码桥（B3 如实记录），不影响语义层。

### 2b. L1 深度序列（已有，三端）

- 价值：给每帧加 3D 结构（相对深度排序、遮挡线索、深度带分层）。消费端（CSG 播放/重建 warm-start）已实证可解可播（胡广生 45 帧秒开预算 68.6KiB）。
- 局限：① MiDaS 输出是**相对深度**（affine-invariant），不是度量深度——CSG 里只能做序关系与仿射归一后的形状，不能标米；② 逐帧独立推理有闪烁（M10 定谳：帧间差 ~92% 是真实运动，wobble 仅 ~36%，深度域稳定化三档全部 FAIL 且劣于基线）；③ 256 分辨率上限。
- 归因提示：M10 的 FAIL 是体积门 FAIL（有效定谳），不是能力缺失；治本已收敛到 M11 MES1 并过门（见 2c）。

### 2c. L2 平面级场景结构（已有，PC 离线）

- 价值：这是当前**最接近「对象轨迹+属性」的可用替身**。225 帧胡广生实测：逐帧 RANSAC K≤16 平面、5 条平面轨道贯穿全片、SPT1 差分编码背景场景图 266,781B、掩码可逆 IoU≥0.995；前景（=非背景平面内点残差超阈区）流 FGS0 289,896B、**225/225 帧前景深度逐位精确**；MES1 掩码事件化+lzma 43.6KB 过 50KB 门，两事件间拓扑/结构正确。
- 局限：① 平面≠语义对象，无类别、无「这是人还是椅子」；② 多前景物体会连成一个残差区，无实例分离；③ 全部工具是 **PC 离线纯 numpy**（tools/*.py），不在纯 Cheng 生产路径，也不在端上；④ MES1 消费端承诺是「结构正确」而非逐像素精确（协议 v1 明示的取舍）。

### 2d. 明确不可用的路线（如实排除）

- **朴素颜色/亮度启发式对象提取**：F5 两轮实测均不稳——border-ring 法稳定提到的是「脸」不是人（深色毛衣与深背景融合），letterbox active-region 法在暗帧上直接失败（active 区 224px 伪数字）。结论：无学习模型的对象提取在本素材上不成立，不要再试第三轮启发式。
- **纯 Cheng 直接读像素做提取**：当前不可行。首帧桥只出 CVPixelBuffer/Metal 句柄，无 CPU/GPU 字节出口（F5 差距 #2/#3）；多帧顺序解码桥缺失（#1）。纯 Cheng 深度推理本身已通（64×64 corr=0.99997），卡的是**喂不进像素**。
- **相机采集**：M16b 真机 HAL 三路全拒（Android M16a 已通）；这是采集缺口，与「存量视频文件→语义」转换无关。

## 3. 完整语义提取（L3）需要什么

按依赖序：

1. **识别/分割模型集成**（核心阻塞）：语义/实例分割模型（SAM 蒸馏、MobileSeg 类）走 MiDaS 已趟平的路——导出→数值锚→端上运行时→对拍。端上运行时已证（M16a pytorch_lite / M16b MindSpore Lite），对拍模板已有；缺的是模型选型、导出链和数值锚本身。**这是工程集成，不是研究突破。**
2. **纯 Cheng 像素字节出口 + 多帧解码桥**（F5 差距 #1/#2/#3）：若要求提取在纯 Cheng 内完成（而非离线/端上旁路）。
3. **实例跨帧关联**：IoU/特征跟踪，把分割 mask 串成实例轨迹。纯 Cheng 无实现；PC 侧 M9c 的平面 tid 跟踪框架可类推。
4. **关系与属性 schema 落地**：A2 合同（docs/specs/csg-semantic-video-v0.1.md）已有字段框架，B2 的 assertion 位在等识别来源接线。
5. 误差门冻结 + 真值标注帧集（F5 步 4 前置条件 4）：没有真值，「准确率」永远是跨帧一致性。

若 L3 之外还要**可自由视角编辑的 CSG 几何**，才进入路径 2 生成式重建研究门（神经渲染），与本清单独立。

## 4. 结论

**partially-feasible。**

- **可承诺（无需任何研究突破）**：实拍视频 → L0 结构语义（纯 Cheng 生产）+ L1 深度序列（三端）+ L2 平面级场景结构与前景残差流（PC 离线工具链，225 帧实测闭环）。这构成「degraded 但有用的 CSG 语义化」：有时间轴、有证据锚、有 3D 结构、有带跨帧身份与参数轨迹的平面级场景图、有逐位精确的前景深度区。局限同样明确：无语义类别、无实例分离、深度是相对深度。
- **blocked 及精确归因**：L3 对象级语义。阻塞点是 (a) 分割/识别模型的工程集成（端上运行时已证可行，缺模型链）、(b) 纯 Cheng 像素字节出口与多帧解码、(c) 实例跟踪与真值标注。**不是**生成式重建研究门——把语义提取阻塞归因于神经渲染未解是不准确的，会掩盖已经可交付的 degraded 路线。
- **建议表述**：对外承诺用「平面级语义化」措辞，不用「对象级」；L3 立项按 §3 清单排依赖，第一刀是分割模型导出+数值锚（照抄 MiDaS 流程）。
