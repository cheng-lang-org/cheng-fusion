# 发现与路线选择

## 已有基础

已读取docs/csg-semantic-video-core-design.md、现有状态恢复交底、因果世界再生交底及B1进度。B1提供规范记录、读写、结构、时间和时钟检查；本轮不将旧测试结论外推为物理模型或世界播放器完成。

## 选择与排除

不选“只改成Merkle根”“只去掉污染列表”“给重建结果增加不确定性字段”作为新专利中心。前两者不能改变必要技术组合，后者已有公开地图不确定性方案。选定交互契约约束的商模型和能力扩张后的历史约束恢复；理论基于已知行为等价，候选创新必须由具体媒体恢复与提交机制论证。

数学边界为有限确定性模型及有限动作域。相同输出、相同动作可用性和相同后继类构成稳定划分；增加动作或输出在同一模型域内形成细化。自由连续世界、任意神经场等价验证、所有存量视频完整物理恢复不在首版可证明范围。

压缩有限状态空间不等于压缩视频字节。首次传输省略的区分信息仍需保存，不能宣称系统总存储同时减少。若像素属于输出合同，不得只核对语义标签；检查器成本和完整依赖必须列账。

## 本轮补检

继承2026-09-16-csg-semantic-video-patent-review目录11件公开文本，本轮追加4件完整权利要求快照至public_records.json。快照含抓取时间、网页哈希和聚合状态；未把Google状态当官方登记簿结论。

1. CN109584343B，独立项1、7、13不以时间污染列表为必要条件。其母案CN104520902B的列表区别不能直接沿用于本分案。旧因果交底已提及该件，本轮补入新路线比较；不假称这件此前不存在。
2. US20210311972A1，核对21及后续项，地图实体与不确定性模型采用分开的层并互相引用。只新增候选或未知字段不能作为创新中心；其授权、同族及国家权利状态仍须复核。
3. US10642607B2，核对独立1、11及从属5，差异代码转逻辑表达式，判断嵌入式程序能否动态更新。出现双模拟词汇不等于垄断全部双模拟应用，也不能因产品场景不同就停止按特征比对。
4. US12470591B2，核对独立1、13、18及从属11，网络攻击图约简、原图映射和补救。证明“合并节点且可映回原图”是公开技术；本稿的媒体合同与历史细化组合仍需创造性检验。

另搜索interactive video equivalence classes、progressive interaction state abstraction、bisimulation compression、video abstraction refinement等组合。返回的抽象图、程序更新、媒体交互资料进一步说明通用图约简与交互均非空白领域；没有把关键词未检出当作新颖性证明。

非专利主资料：Givan等2003年模型等价与最小化论文、SRI的Proof-Carrying Architectures摘要、SimReady Benchmark、OpenExec、MPEG-I场景描述。SRI本轮搜索结果取得原站摘要，再次open发生超时；仅据该摘要讨论“检查抽象和细化”的已知一般方向，未声称核读全文。其余链接已打开。公开日期判断以资料实际日期为准，不采用搜索引擎抓取时间。

## 拟议保护核心

原媒体包包含：合同约简的商模型、入口候选集、区分资料目录。新请求触发：恢复资料、重放已发生历史、求当前候选集、构造并检查细化映射、同一新类才原子切换、多类则保留歧义。这个组合是检索和申请论证对象，不单独主张双模拟、缓存、哈希、来源或模拟分支。

CN118196277A关于视频三维重建与交互的独立项仍贴近产品目标；额外增加本稿步骤不自动避开他人基础专利。CN109584343B、协同场景图和动态对象视频指令相关专利随实际组件选择继续核对。申请条件、侵权判断和标准许可分开。
