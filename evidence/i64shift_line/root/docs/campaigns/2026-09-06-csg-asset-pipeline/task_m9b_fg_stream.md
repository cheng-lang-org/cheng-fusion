## 1. 前景流格式 v0 定稿（FGS0）

**语义**：逐帧只存前景区域的深度。前景 mask 定义 = 该帧像素**不属于任何背景平面内点**（`|d_u8 − 平面模型值| > 12` 对全部平面皆不满足），即「帧对背景场景图重建深度的残差超阈掩码」——不是帧间差分掩码。前景深度存 u8 量化绝对值（非残差），解码零漂移。

**量化域**（与 M7-pack / M8a 全流一致）：`u8 = clip(floor((d − 30.90658950805664) / 1191.7901878356934 × 255 + 0.5), 0, 255)`，lsb = 4.6737 MiDaS 单位。前景判定阈值 = 12 u8（M8a 同参，RANSAC 内点界）。

**文件布局**（小端）：

```
Header (32B):
  magic "FGS0" 4B | version u16=0 | flags u16=0
  width u16=128 | height u16=256 | frameCount u16 | fgThresh u8=12 | reserved u8
  quantDmin f64=30.90658950805664 | quantDmax f64=1222.69677734375
FrameOffsetTable: frameCount × u32   (帧记录相对帧区起点的偏移, 支持随机访问)
帧区起点 = 32 + 4×frameCount = 932B (225 帧)

每帧记录:
  nFg u16 | planeCount u8 (该帧背景平面数, 供背景线对账) | rleSegCount u16
  maskRLE: rleSegCount × u16   (0/1 交替 run; 首 0-run 可空; 尾 0-run 省略,
                                单 run ≤ 32768 < 2^16 恒不溢出)
  fgDepth: nFg × u8            (前景像素量化深度, 行序 = mask 展开序)
```

背景场景图（M9a 线产，本轮未就绪）：占位两口径并列——场景级「6 平面 × (a,b,c) × f4」= 72B（任务书字面口径）；逐帧平面实证件 `bg_planes.f4`（每帧 planeCount u8 + K×3×f4，f4 即存储精度）= 14,361B。

## 2. 实现与背景模式选型（实测）

背景平面模型 = M8a 同法 RANSAC 仿射平面（u8 域 `d = a·x + b·y + c`，LCG 种子 20260912、256 迭代、K≤16、判停 <0.5% 增量或 <1% 占比，与 `semcov/m8_ref_check.py` 逐行同构；帧 0 对拍：K=5、覆盖率 99.158%、五平面参数三位小数全同）。两模式全 225 帧实测：

| 模式 | 前景流 | 背景 | 合计 | 前景占比均值 | 前景占比最坏 | 备注 |
|------|--------|------|------|--------------|--------------|------|
| **A 逐帧独立 RANSAC** | **289,896 B** | 14,361 B | **304,257 B** | **1.340%** | 2.99% | K∈[1,8] 逐帧自适应 |
| B 帧 0 模型 + 逐帧最小二乘重估 | 942,508 B | 13,725 B | 956,233 B | 8.698% | **56.64%** | 固定 K=5；背景重组帧平面不够，前景爆炸；86 次退化平面沿用 |

**选定 A**（合计为 B 的 31.8%）：背景逐帧重组（镜头/人物运动）下，帧 0 固定平面结构撑不住（帧 45 前景 14.3%、最坏帧 56.6%），逐帧 RANSAC 让前景占比始终钉在 M8a 的 0.07–1.97% 量级（全 225 帧均值 1.34%）。代价是背景平面跨帧无结构对应——该对应属 M9a 场景图职责，不阻塞本流格式。

## 4. 可逆校验（从磁盘解码对拍，真实运行）

```
fgBitexactFrames  = 225/225   前景区逐位 BITEXACT（存原量化值，解码放回构造恒等，实测通过）
bgMADu8Mean       = 3.844     背景区平面近似残差 MAD（最近平面口径；逐帧 2.94–5.50）
bgResidualMax     = 12.0000073  背景残差上界 = 阈值 12 + f4 存储精度边界（12+ε，无越界）
u8BgMaxDiffWorst  = 12        u8 取整交付形态背景区最坏位差
fullMADu8Mean     = 3.785     全图 MAD（前景精确 + 背景平面近似）
```

责任边界如实分列：**前景区零损失是本流（M9b）的证明责任，225/225 逐位通过**；**背景区是 M9a 的责任边界**——平面近似残差 MAD 3.84 u8（≈0.39 全量程 lsb + 余量）由仿射平面模型精度决定，不是前景流引入的损失。背景重建口径：每个背景像素取残差最小平面的模型值（M9a 场景图消费的真实形态）。

## 5. 判据落位

判据：前景流 + 背景合计 < 单层深度流（14.4MB）的 10%（1.44MB）即显著收益。

- 占位口径：289,896 + 72 = **289,968 B = 2.01%** → PASS
- 逐帧平面口径：289,896 + 14,361 = **304,257 B = 2.11%** → PASS

收益为阈值的约 1/5，余量大：即使前景占比翻 4 倍或全量加帧间差分前的保守形态，仍远低于门。
