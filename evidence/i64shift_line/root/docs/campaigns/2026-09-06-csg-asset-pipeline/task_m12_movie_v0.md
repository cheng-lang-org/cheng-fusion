## 1. 素材适配（镜头深度 → 128×256 竖幅栈，零探针模块改动）

镜头深度与 hgs 竖幅产线有两处格式差，适配如下（全部落盘可复现）：

| 差异 | 镜头素材 | hgs 栈 | 适配 |
|----|----|----|----|
| 帧方向 | npy (128,256) 横幅（1280x720 源，MiDaS small 原生输出） | npy (256,128) 竖幅（720x1280 竖拍源） | 逐帧 `.T` 转置落盘 `lens_pipeline/depth_transposed/`（C 序 (256,128)，与 hgs 布局同构；转置后逐位核验 `reshape(256,128)==orig.T` PASS）。WB/WC 全部数学在转置域进行，WC 出图 `--view-transpose` 再转置回横幅 256×128 |
| 量化域 | 每镜头全流全局域（manifest `depth.quant`） | 30.9066/1222.697 全流固定 | pipeline 新增 `--qmin/--qmax` 注入 M9A/M9B/M9C（M9E/M11/SPT1/MES1 头经 M9C 活引用自动生效）；WC 从 FGS0 头读量化域。三镜头注入值与 f4 全流实测 min/max 逐位一致（L084 21.656145095825195/943.5565185546875，L057 0/1085.455078125，L052 0/1120.47607421875） |
| 帧数 | 424/324/88 | 225 | 既有 `--frames` 覆盖注入；WC 轨迹步长 `stride=max(1,(N-1)//44)`（hgs 公式复现：225→5），轨迹恒 45 帧覆盖全片 |

工具参数化改动（不改任何数值算法路径）：

- `tools/csg_lens_pipeline.py`：`--qmin/--qmax/--base-mp4/--src-video` 注入；帧 0 M8a 纯 Cheng 数值锚与 m9d/m11/m9b 逐字节锚按 `anchors_on` 门控（非 hgs 素材如实记 skipped，与 WB 文档「参考物缺失不伪造」同法）；体积账增加按镜头帧数归一的单层基准（`frames×64KiB`）。**hgs 默认无参行为不变**（帧 0 锚定、SPT1/fgs0/mes1 全部锚定路径原样）。
- `tools/csg_render_eval.py`：`--depth-dir/--frames/--scene/--scene-obb/--fgs0/--bg-f4/--ref-rgb/--ref-png-dir/--out/--view-transpose`；量化域从 FGS0 头读；纹理支持镜头 ref PNG（1280x720 → resize 256x128 bicubic（深度产线同口径）→ 转置竖幅，与转置深度逐像素同构）；M9a 逐位自检门控（regionPx/polygon 硬校验任何素材都跑）。**hgs 默认无参行为不变**。

## 5. 过程中发现并修复的缺陷（真实对拍暴露，非计划内）

1. **`csg_box_merge.min_area_rect` 盒中心坐标系错位（真 bug，已修）**：返回的中心是旋转矩形坐标系下的分量，而两个调用方（`csg_box_merge.main` 与 WB 移植的 `build_boxes_v1`，同式 `front_c = c2[0]*u + c2[1]*v + D_a*n_a`）都按 (u,v) 原始坐标系数消费。矩形主轴不与坐标轴对齐时盒中心错位：L084 box0 实测 center z=−4.5 而支撑域 z∈[56,185]（OBB 渲染覆盖率塌到 1.5%）；hugs p1/p2/p4 同病（中心偏差达 40，被轴对齐大盒 p0 的正确覆盖掩盖，故 hgs OBB 渲染 95%+ 从未暴露）。修复 = 中心按 `(mid_pu,mid_pv)·(ax,ay)` 转回原始系，调用方契约不变。修后 L084 OBB 覆盖 76–86%、侧面补缝千像素级，体积补缝语义真实工作。
   **波及如实上报**：hugs 归档产物 `artifacts/csg_asset_pipeline/huguangsheng/boxmerge/scene_frame0_v1.json`（及旧 WB `lens_pipeline/lens_scene/scene_v1.json`）由带病代码生成，旋转矩形盒中心错位；本任务无权改该目录，修后在 scratch 内复跑 hgs WB 字节锚对旧产物 FAIL（18112 vs 18111B，p1/p2/p4 中心修正所致）——M9d/WB 产物需由归属任务重跑再锚定。上游 M8a 帧0 纯 Cheng 锚定修后复跑仍 PASS（平面/跟踪/MES1/FGS0 路径不经过 min_area_rect）。
2. **渲染器退化平面守卫（已加）**：L052 帧 28/51 深度存在 v≈0 饱和域（行车镜头远区），RANSAC 合法拟合出 (0,0,0) 退化平面（≥328 内点，FGS0/bg_planes.f4 如实记录）；该平面法向量为零无 3D 几何，渲染除零崩溃。`render_bg` 跳过零仿射平面（`greedy_claim` 的 pred>0 条件本就使其永不认领），像素由其余平面/黑底承担，MAD 照实入账。
3. **np.save 转置落盘 fortran_order 陷阱（过程坑）**：`.T` 视图直接 np.save 会写 fortran_order 布局，而栈内 load 按裸字节 C 序读——必须 `np.ascontiguousarray` 后落盘（已修，转置逐位核验通过）。
