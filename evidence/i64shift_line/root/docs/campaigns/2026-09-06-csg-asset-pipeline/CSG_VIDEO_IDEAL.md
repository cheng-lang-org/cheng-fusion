# 理想 CSG 视频形态——架构文档（终极目标定义）

> 状态：vision（2026-09-13 定稿）
> 定位：本战役全部原子任务（S/D/V/I/A 编号体系）的架构基准与验收依据
> 一句话：**理想的 CSG 视频不再是「像素的时间序列」，而是「一个持续存在、可交互的 3D 世界 + 一台在时间轴上运动的虚拟相机」——观看=在这个世界里取景，播放=求值渲染，编辑=改基元重模拟。**

---

## 0. 与传统视频的本质区别

| 维度 | 传统视频（H.264） | 理想 CSG 视频 |
|---|---|---|
| 载体 | 压缩像素帧序列 | 语义基元的持久 3D 世界 + 时间轴参数/事件 |
| 秒发 | 分发码流/分片 | 发布=场景资产内容寻址注册即就绪（对象模型） |
| 秒开 | 传完整首 GOP 给解码器 | 首关键帧 chunk 零解码直渲染（SSM1 实测预算 56-130KB） |
| seek | 受 GOP 边界约束 | O(1) 时间轴索引（实测与 GOP 距离无关） |
| 体积 vs 时长 | 码率×时长 线性 | 场景一次建模+动态增量（背景只存一次） |
| 观看体验 | 固定视角平面，画质出厂定型 | 自由视角/任意分辨率/物理交互/可编辑 |
| 生态 | 成熟编解码生态 | 基元流渐进加载+语义可编辑+空间检索 |

## 1. 结构层 S（Structure）：世界是语义基元的持久组合

**理想态**：场景由 CSG 布尔运算的几何基元构成（墙=盒挖门窗、桌=板+腿、地形=平面+高度场），每个基元携带材质/物理属性/语义标签；基元**持久存在**，不随帧出现消失；分辨率无关（按需细分）。

**已证**：
- 背景结构可拟合：胡广生 K≤6 仿射平面覆盖 98.03-99.93%（task_m8_semantic_coverage），journey 98.25-99.65%（task_m8c）
- OBB 基元升级：斜视角无限薄穿帮实测消除，几何描述缩 5.8x（task_m9d_box_merge）
- 全镜头 OBB 序列：S1 线（在飞）
- 场景图序列化：SSM scene layer v0/v1 JSON（task_m9a_bg_csg）
- 语义分层通则：K=16≥80% 判据成立（胡广生+journey 双素材，task_m14）

**Gap 与路径**：
- 有机体（人物/织物/流体）不是 CSG 基元能表达 → **混合表示**：CSG 结构层+神经前景层（前景流 FGS0 已证 290KB=2.01%，task_m9b）
- 语义分割辅助精度提升：A2 线（在飞）
- 材质/属性字段扩展：S3（待立）

## 2. 动态层 D（Dynamics）：时间轴是参数动画+物理事件

**理想态**：基元参数是时间轴上的动画曲线；物理行为由参数驱动模拟（重力/碰撞/布料）；时间维只存「状态变化事件」；重放=同一初始状态确定性重模拟。

**已证**：
- 掩码事件化 MES1：**43,565B < 50KB 门**（v0 逐帧掩码 266KB 的 0.16×，6.1× 压缩），播放 MAD +14.8% 门内（task_m11）
- **通则判定**：journey 密度减半→等时长 17.5KB 仍 PASS（task_m14）；双线性模型（体积∝事件密度×单事件还账+参数流固定成本）自洽
- warm-start 跟踪：跨帧匹配率 39.6%→98.8%（task_m9e）
- 组合收口：warm-start GT × MES1 = 背景时间维完全闭环 78×（task_m13）

**Gap 与路径**：
- 参数流固定成本（60s 尺度瓶颈）：v1.1 varint run 编码（M14 §边界）
- 长间隔素材 max-gap 守护条款（M14：journey 播放 MAD +45.2% 归因掩码冻结）
- 物理参数逆向：D2 线弹跳球受控实验（在飞——g/e/v0 逆向+重演对拍）
- 推理期时序一致深度模型：M10 定谳后处理治不了，需推理期模型（治闪烁，另立）

## 3. 视角层 V（Viewpoint）：相机是自由实体

**理想态**：相机是场景中的自由实体（任意位置/朝向/焦距）；观看者可离开导演机位自由取景，也可回到导演视角；disocclusion 由场景几何外推自然解决（背景延伸是几何性质）。

**已证**：
- 场景图求值渲染：正视角 224/225 帧逐位相等（task_wc_render_eval）
- 自由视角轨迹：A（±10px 平移）/B（15° 弧）各 45 帧全片 mp4，三判据成立
- OBB 补缝：无限薄穿帮实测消除，斜视角覆盖 93.7%→96.8%（task_m9d）
- 真机求值：鸿蒙 covered 随位姿 94→64.9→33.8%（N 线复验）
- 真机自由视角上屏：N2 双轮实证（task_n2_frame_sync）
- disocclusion 三策略对比：V1 线（在飞）

**Gap 与路径**：
- 大偏移（>30°）disocclusion 需生成式填充——超出确定性管线范围（诚实边界）
- 渲染真机化：N 线求值统计已证，上屏帧同步 N2 轮（在飞）

## 4. 交互层 I（Interaction）：观看者是世界里的操作者

**理想态**：拿起/移动/删除基元、改物理参数重放、多观看者同世界各取视角；重放=确定性重模拟。

**已证（上游）**：csg_player 确定性物理+climb/walk 场景；SSM1 全链确定性（锚定链 assert 全过）。

**Gap 与路径**：
- 基元交互探针（拖动平面/OBB→场景图变→重渲染）——I1（待立，WC 渲染器已具备能力）
- 视频逆向物理参数——D2 线弹跳球探针（在飞）是第一步
- 多观看者共享世界——归 libp2p 多人同步战役

## 5. 获取层 A（Acquisition）：存量视频→CSG 的转换管线

**理想态**：任意存量视频 → 语义分割 → 基元拟合 → 材质估计 → 物理参数推断 → 场景图+动画曲线。

**已证**：
- 转换产线：MiDaS 深度（corr 0.99998）→ 混合表达（背景 98%+ 平面化 + 前景流 2.01%）+ base 音画（WA/WB 全链）
- 固定机位：解析基元路线最优（M8/M9 全链）
- 运动相机：3DGS 动态重建路线明确（条件矩阵见对话定谳）
- 电影级：Carnival of Souls 94 镜头基准集+三代表镜头 v0 全链 PASS（task_wa/task_m12）

**Gap 与路径**：
- 语义分割辅助：A2 线（在飞）
- 运动相机 3DGS 路由：A1（待立，需运动相机素材）
- 有机体完整 CSG 化：研究级（诚实边界——混合表示是当前最优解）
