# 评测合同（任务 02 冻结件）

状态：`frozen-for-10+`。任务 10 数据与模型选型、11 本地决策后端、12 校准、13 Jev 对照、14 融合验收共用本合同；改动须回写并记 progress。

## 1. 数据门（任务 10 执行）

- 训练前冻结：数据清单、来源许可、标注规则、训练/校准/最终测试划分、去重及泄漏检查。
- 划分按应用、任务模板和语义族隔离，不是只随机拆句子。
- 必备切片：陌生领域、候选顺序置换、同名歧义、无匹配（no-match）、噪声、指令注入、证据不足。
- 产物：`data_manifest.md`（来源/许可/哈希/划分审计）。

## 2. 指标门（任务 11/12 执行）

| 头 | 指标 |
|---|---|
| Choice | 准确率、宏 F1 |
| Noul | Brier、NLL |
| Score | 与标注的等级误差、分布损失 |

- 校准：冻结分桶的可靠性统计并附样本量，不允许只给一个 ECE 标量；阈值只在校准集选择，最终测试不调参。
- 有限候选分布的归一值不是自然语言事实的绝对正确概率；集中度不冒充正确率。
- 语义错误如实计错，类型合法不冒充正确。

## 3. 公平比较门（任务 13/14 执行）

冻结四组，在看最终数据前冻结样本量设计、分层权重、重复次数、统计方法与声明阈值：

1. 通用执行宿主＋Jev（公开宿主与适配版本，系统基线）
2. CSG＋Jev（隔离 CSG 收益）
3. CSG＋本地决策模型（隔离模型替代效果）
4. 纯 CSG（仅完全形式化任务子集计分；开放语义任务记不适用，不得排除后宣称全覆盖）

- 模型对比：相同证据、完整候选、目标、权限、超时口径。
- 系统比较：允许 CSG 减少步骤，但最终目标及可获得信息一致；CSG 内部特权状态与仅看屏幕的基线不得混为同条件。

## 4. 声明门（任务 14）

- 最终声明门：语义质量差与任务成功率差的配对 95% 置信区间下界均不低于 0；错误操作无新增且关键拒绝测试全部通过；预先选定的总耗时或总成本指标有统计支持的改善，另外一个无退化。
- 达不到就报告权衡或未定；不以单次快跑宣称超过；测试集零错误不解释为普遍零风险。
- 13 对照缺测（无凭据/预算）不阻断本地功能验收，但对照结论与"覆盖/超过 Jev"的任何宣传保持未完成。
