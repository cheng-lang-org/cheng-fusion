### 1.3 程序构造数据（非捏造：生成规则透明、生成器哈希绑定）

困难切片的构造器（§4）与候选置换等变性数据均为程序生成：输入取自 1.1/1.2 的真实样本，变换规则在冻结件中逐条声明，绑定生成器源哈希。这与「不可捏造数据」不冲突——捏造指虚构测量/结果；此处是声明完整的确定性变换。

## 2. 去重与泄漏检查规则（按隔离划分，非随机拆句）

1. **三层隔离键，任一跨 split 重复即拒**：
   - 应用域：UniMaker 任务域 / 新闻域 / 金融域 / 科学域 / 通用桌面域，互斥；
   - 任务模板指纹：prompt 模板 + 候选集骨架的规范编码哈希（同一模板的不同实例不跨 split）；
   - 语义族：任务意图簇（如"发布""搜索""筛选"）与 NLI 前提-假设对簇，人工冻结簇清单。
2. **机械去重**：归一化（NFC + 去首尾空白）后精确指纹去重；n-gram 重叠阈值去近重尾，阈值与 n 在冻结件写死，不在线调。
3. **置换切片防泄题**：候选顺序置换实例**只进测试/校准**，其原型不进训练（否则等变性被背下来）。
4. **域间泄漏**：1.2 的公开集样本与自有集若语义族重叠，重叠簇整体划入最终测试侧，不参与训练。
5. 每条数据带来源 ID + 采集/生成器版本，进入冻结清单哈希；split 归属由隔离键决定，不做纯随机抽样。

## 5. 标注规则草案（三头各自的标注合同与验收抽检）

### 5.1 Choice（动态候选分布）
- 每条样本 = evidence 文本 + **完整候选列表**（顺序即呈现顺序）+ 唯一 gold 候选索引；gold 语义绑定候选身份，候选重排时 gold 必须随身份迁移（由 4.2 生成器保证）。
- no-match 是显式标注值，不是缺省。
- 验收抽检：自有数据 ≥10% 双通道独立标注（程序 gold + 人工复检），不一致率 >2% 时整批返工；公开集派生的 Choice 抽检 ≥10% 人工核对 gold 可还原。
- 程序生成的置换/注入切片抽检 5%（生成器正确性由独立断言覆盖）。

### 5.2 Noul（条件成立概率）
- 每条 = 条件文本 + 证据文本 + 三值标注：成立 / 不成立 / **证据不足**。
- 概率目标映射在校准集拟合时冻结（草案：成立→1，不成立→0，证据不足→单独校准通道或 0.5 映射，二选一，选择须写入任务 12 冻结件；训练目标用标准分类/二元概率损失，与提案 §3「不声称复现 RLCD」一致）。
- "证据不足"标签只允许由 4.7 规则生成或人工显式判定，禁止标注员拿不准时默认填它。
- 验收抽检：≥15% 双人独立标注，Cohen 一致性按三值混淆矩阵报告，<0.8 返工。

### 5.3 Score（有序等级分布）
- 每条 = evidence + 评级对象 + 等级 1..K + **每级 anchor 描述**（anchor 先冻结再标注）；K 与 anchor 随首个 Score 应用场景在任务 11 前冻结。
- 一致口径：双标等级差 ≤1 记一致，差 ≥2 返工；抽检 ≥15%。
- 来源优先级：自有应用真实执行强度记录 > 公开有序集（现清单内无已核实公开有序集，若有候选须补许可核实，不硬凑）。
