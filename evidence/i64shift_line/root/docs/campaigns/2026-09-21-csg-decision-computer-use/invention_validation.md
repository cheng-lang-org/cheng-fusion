## 2. 待验证区别特征

| 编号 | 候选区别特征 | 已知相邻技术 | 当前结论 |
|---|---|---|---|
| K1 | 同一受限语义定义生成实际模型输入依赖、候选查询成员资格依赖和动作校验器 | 模型驱动代码生成、查询编译、程序依赖分析 | 组合是否已公开/显而易见未定；需要具体转换规则，不能仅称“一张图” |
| K2 | 异步学习样本绑定输入及完整候选；依据不变时跨快照重绑定身份，且保留样本语义 | 增量计算、缓存键、模型服务缓存 | 最窄可研究点，仍有常规组合风险；尚无实现或证明 |
| K3 | K1 生成的依赖描述直接用于原生事务的提交校验，覆盖未出现候选的插入影响 | 乐观并发控制、谓词锁/范围验证、幻读防护 | 仅“检查版本”无贡献；要说明生成与消费关系带来的具体技术效果 |
| K4 | 提交回执更新相同判断图并驱动下一世代，保持事实/概率区分 | 事件驱动工作流、类型系统、审计日志 | 辅助实施特征，当前不作为独立核心发明 |

创造性分析应按最接近现有技术→实际区别→实际技术问题→结合启示进行，不能先选择很多组件再以数量证明创新。场景替换、无技术贡献特征及充分公开要求参考[现行指南修改解读](https://www.cnipa.gov.cn/art/2025/12/4/art_66_202935.html)。

## 3. 绕开与保护边界

| 替代实现 | 能否避开候选骨架 | 需要实测的代价或等效性 |
|---|---|---|
| 每次全量重推理，提交时全快照验证 | 可能避开选择性复用特征 | 无关更新频繁时推理数；低变更时可能更省内存更简单 |
| 推理期间全程锁定有关状态 | 可能避开跨版本复用/失效特征 | 并发写入延迟、锁持有时间；低并发可能完全可接受 |
| 手工写出完整且正确的依赖及校验器 | 可能避开同源自动生成特征 | 运行性能可能等同，不能捏造性能劣势；比较变更时一致性维护成本 |
| 运行期跟踪输入读取与查询依赖 | 可能避开静态生成步骤 | 完整性、访问记录开销、对集合插入的捕获；也可能同样有效 |
| 用分布式组件共享绑定协议 | 换组件位置不必然避开方法关系，但不能预判侵权 | 实际实施者、跨地域执行和侵权取证难度须法律分析 |
| 换语言/模型/索引类型/哈希 | 若不属于必要限定，仅替换它们未必改变关系 | 不将产品名称当保护核心；仍以正式权利要求为准 |

独立权利要求加入的每个必要特征都有被舍弃的可能。目标是在足以区别现有技术的前提下保护实质贡献，不承诺覆盖所有可靠 agent。内部闭源算法难取证；应提前记录可合法观察的协议行为、错误码、回执及公开实现证据，不能假定能拿到对手源码。

## 4. 实验设计（待执行，非结果）

冻结同一真实应用、任务输入、权重及配置、硬件、授权和状态更新序列。模型决定错误、过期提交、未授权执行、超时分开计数。受控交错测试可以用确定性节点隔离事务正确性，但不得冒充真实学习模型质量实验。

对照配置：完整拟议方案；每次全量推理+全快照验证；推理期间持锁；人工维护但语义等价的完整依赖+事务验证；运行期完整读取/查询跟踪。后三者不能刻意实现成有缺陷的弱基线。另设消融：去集合依赖、去模型配置绑定、把验证移出提交事务；消融仅用于测试，禁止进入产品。

| 测试 | 注入的真实变化/条件 | 验证标准 |
|---|---|---|
| 对象 ABA | 删除重建同名对象、复用槽位 | 旧身份不得提交，须 canonical identity 重绑定；不以名称相等判同一对象 |
| 候选幻读 | 原 A/B 未变，插入匹配 C；删除/改变未选候选 | 查询完整性依赖改变，原绑定被拒；不能只检查所选对象 |
| 顺序/负查询 | 排序键变化；原先无匹配后插入；分页边界变化 | 输入或候选顺序相关依赖被捕获；无匹配不是无依赖 |
| 无关写入 | 写入不影响输入、权限、候选查询或前置条件的状态 | 允许保留同一样本，提交仍做权威验证；与全量基线比较推理次数 |
| 隐式输入 | 目标参数、输入模板、tokenizer、模型、校准、解码配置变化 | 绑定失效；未声明外部时间/随机状态/网络输入不准入可复用模式 |
| 检查到提交竞争 | 校验后注入并发变更、权限撤销 | 在实际存储边界验证拒绝或可串行化顺序；不得出现越权提交 |
| 事件乱序/遗漏 | 状态已提交但通知尚未送达或次序反转 | 提交时权威复验仍拒绝失效结果，不依赖消息及时性保证安全 |
| 更新风暴与饥饿 | 高频相关变更、持续无关变更 | 报告失败率/重试次数/超时；不能仅展示最有利无关变更场景 |
| 生命周期 | 取消、迟到结果、提交回执丢失、重启 | 资源释放；未确认外部效果不得盲重发；真实提交与回执对齐 |

记录：任务成功率与错误类别；推理次数；重算节点数；模型输入字节；提交拒绝数；p50/p95 延迟；锁等待；逐相内存及回收后留存。样本量、工作负载分层、重复次数和统计方法在看结果前冻结；不预填提升百分比。模型随机性用固定样本保留合同解释，不能把重复抽样差异算成缓存错误。

实现影响模型：观察相增加依赖记录；候选相增加查询/顺序依赖；调度相增加反向边和有效性状态；推理相保留样本与工件身份；提交相增加读集和消费记录；回收相限制保留世代数。空间外推为实际依赖行数×实际行宽＋边数×边宽＋索引容量＋绑定/事务记录，数值全部待测。沿用唯一约束卡：峰值 ≤768MiB、逐相贴线、rc=0，RSS 与模型差 >50MB 解释，不能抬门。
