# CSG语义视频标准实施审查与修订

日期：2026年9月16日。范围：中国实施为主，补查已知美国相关技术及同族线索。性质：基于公开权项和当前本地文件的初步实施自由审查，不是完整FTO意见或侵权裁判。

## 1. 本次结论

现有资料不足以宣布CSG标准或产品侵权，也不足以宣布无第三方专利风险。审查了11份公开/授权文本，其中8份为中国文本、3份为美国文本。最需要在接线前核对的处理链是：语义索引图生成与播放、跨帧缓存重算、双向场景增量同步，以及视频重建后识别并修改对象。神经压缩和强化学习只是风险的一部分。

已修改标准的实现选择边界，保留数据与正确性要求，不强制具体神经网络、语义颜色索引、跨帧污染列表或云端排序协作流程。已增加8条专利与实现选择规则。冻结schema的第1至6节和现有semantic_video源码不因本次审查改变；并未声称通过改文档消除了实现中的全部风险。

标准原稿是研究方案；当前另有冻结的v0.1字段规范和B1格式实现。两者必须分开评价。生产入口、实采和完整世界恢复尚未以本次审查取得实现验收；B1格式校验通过不能充当补偿算法或商业实施自由证明。

## 2. 判断方法及资料边界

对每项被审查权利要求分别比较全部技术特征，不把多个专利的零散特征拼成一个侵权权项。独立方法、设备、系统、介质及程序产品均可能有不同范围。说明书中的例子不当然构成独立项限制；从属项的附加限制也不能强加给独立项。根据[专利法第十一、十三、六十四条](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)和[最高法相关解释第七条](https://ipc.court.gov.cn/zh-cn/news/view-31.html)，实施行为、权利范围和公开申请的临时保护须分别处理。公开申请后续授权及权项变化可能影响费用请求，不能把A文本视为没有风险。

下列拆解为技术释义，不取代原文或法院解释。“标准未强制”表示可互通性不必依赖该流程，不表示某个实现没有采用。“当前格式层未见”仅限已核读文件，不扩展到整个CSG、第三方库或平台固件。“潜在覆盖”表示存在应进一步比较的具体链路，不表示已经侵权。

权利状态来自Google Patents页面，页面自身声明状态为推定。已取得权项正文及页面身份；尚未取得CNIPA/USPTO正式登记簿、年费记录、全部审查修改和无效决定。对CNIPA网站的公开号定向网页搜索未取得这些正式文件，不以搜索无结果认定失效。B文本说明存在授权公告，不等于已经核准当前维持有效；A文本页面Pending也不能替代实时登记。

本次没有穷尽语义搜索、对象追踪、压缩标准专利池、三维重建和网络协议全部权利。外部公开文本保存于[公开记录](public_records.json)，含URL、抓取时间和页面哈希；法律状态均标明非官方登记核验。跨地区实施须按当地法律补做分析，不能将中国比对结论直接套用美国。

## 5. 本次标准修订
