# 承道合一出海合规架构

> 版本：2026-08-21 工作备忘（含中间形态：开放协议 + 新加坡双核）。覆盖 Cheng、UniMaker、具身智能、RWA 四条线；路径为境内产业母体 → 新加坡开放中间层 → 美国商业落地 → 开曼封闭式基金战略持股/赎回。  
> **这不是法律意见。** 落地必须由中国 ODI/数据、新加坡公司与基金、开曼 ELP/CIMA、美国 CFIUS/出口管制四地持牌律师按当时有效文本出备忘录。

## 结论

四条业务不能装进同一家运营公司。承道合一只做境内产业母体；**中间形态不是开曼控股壳，也不是特拉华 C-Corp**，而是新加坡双核：协议层用担保有限公司（CLG）做开源 steward，商业层用 Pte Ltd HoldCo 接许可费和开曼基金。开曼最多设两只隔离、**封闭式**基金——Tech Fund 只持商业 HoldCo / Cheng / UniMaker / 具身的新加坡股权，RWA 基金只持受 MAS / 证监会路径约束的代币化产品。

三条原则：

1. 境内基础设施、牌照、个人信息、重要数据留在境内法人。出海卖许可、接口、交付能力，不是把资产搬家。
2. 新加坡必须有人、有租、有账、有决策。空壳新加坡加开曼控股，837 号令按实质重于形式穿透，ODI 和安全审查照样做。
3. 开曼基金是外部资本工具，不是境内公司的影子股东，也**不是开源协议的所有人**。基金买新加坡商业公司的股权或赎回自身份额，不能绕开 ODI 去买境内股权，也不能当 VIE，不能控股 steward。

境内禁止发行 RWA；具身智能默认不把控制权放进美国。先把 Cheng + UniMaker 的新加坡许可和 Tech Fund 做实；具身只做非控制的海外交付；RWA 单独持牌、单独基金。四条线共用品牌可以，共用法人和钱包不行。

开放三件事、封闭三件事：

| 开放 | 封闭 |
|---|---|
| Cheng 语言 / 编译器 / CSG 规范（OSI 许可证） | 境内源码主库、自举链、训练数据、厂区点云 |
| 新加坡商业 HoldCo 的股权（可增资、发优先股、接 LP） | 开曼基金本身（对 LP 封闭，不对境内公开募集） |
| 海外镜像与文档、SDK、对象代码许可 | RWA 钱包、智能合约运维、境内用户账号 |

「开放」不是开曼开放式公募，不是把唯一源码放到 GitHub 美国账号，不是向境内居民卖 RWA。OSI 公开树必须先走技术出口分类；未获许可的层不得上网。

## 中间形态：开放协议 + 新加坡双核

承道合一的定位是 **AI 原生基础设施**，价值在网络效应（语言、编译器、CSG 被人和模型共同用），不在把编译器锁进开曼壳里卖断。开曼基金要的是可赎回的经济权；基础设施要的是不可被 LP 关掉的协议。这两件事必须拆开，中间层就是拆开的地方。

### 为什么不是别的中间层

| 中间形态 | 看起来像什么 | 为什么不是最优 |
|---|---|---|
| 开曼 Ltd 红筹 HoldCo | 传统上市架构 | 封闭、CFIUS 磁铁、无实质、837 照样穿透；基金和运营公司粘在一起 |
| 特拉华 C-Corp | 硅谷 AI 默认 | 中资控制的 AI 基础设施放进美国公司：入境 CFIUS、美国 LP 的 OISP、EAR 分类全部叠上 |
| 香港壳 + 开曼基金 | 常见 ODI 过路 | 香港在 OISP 口径里按中国处理；不能当免审层 |
| 新加坡 VCC 兼做公司和基金 | 「一个主体全搞定」 | 运营公司和资金池混装；RWA 牌照风险灌进编译器主体 |
| 开曼开放式基金 | 随时申赎 | 基础设施周期与日频赎回冲突； Mutual Funds Act 更重；对内稍有宣传就变非法公募 |
| 只开源、不设法人 steward | Git 仓库当中间层 | 许可证、商标、CLA、漏洞披露没有主体；第一笔机构 LP 进来就会抢控制权 |

### 推荐形态（理论最优且可落地）

```
承道合一（境内 AI 原生基础设施运营）
        │ 可撤销独家许可：对象代码 / SDK / 文档
        │ 源码主库、自举链、训练数据留境内
        ▼
新加坡 Cheng/CSG Steward（担保有限公司 CLG，无股本）
        │ 开源许可证、商标、贡献者协议、规范冻结、漏洞披露
        │ 基金不得持股、不得协议控制
        │ 成员：商业 HoldCo + 独立维护者；章程锁死「不得关闭开源许可」
        ▼ 规范与开源发行
公开镜像（新加坡管辖的 git；GitHub 只做镜像不当事主）

新加坡 Commercial HoldCo（Pte Ltd，有人有租有账）  ◄── 开曼 Tech Fund 只买这里的可赎回优先股
        ├── Cheng Tech Pte     开源核心之上的许可、支持、认证、私有加速
        ├── UniMaker Pte       产品与分发（开源核心 + 商业制作器）
        └── Embodied Pte       海外集成；美国不控
```

两句话：

1. **协议开放、公司开放股权、基金封闭。** Steward 没有可供基金挤压的利润；HoldCo 才是基金的交易对手。
2. **开源的是发行物，不是管辖。** 对外 OSI 许可从新加坡 steward 发出；权威源码和自举链仍在境内，**先做中国技术出口分类（必要时许可证）和美国 EAR 分类，再出镜像**。未获许可的层不上公开树。唯一正本放在 GitHub 美国账号 = 把编译器管辖权交给美国法院。开源不是免安审：把境内长成的编译器 / Agent / 模型权重无偿挂到全球公网，在出口管制口径里同样是「向境外提供技术」，比卖给一家公司扩散面更大。

### 开源与商业怎么切（open core）

| 开放（steward 发行） | 商业（HoldCo 收费） | 绝不开源、不出境 |
|---|---|---|
| Cheng 语言规范、编译器可自举的公开树、CSG 规范 | UniMaker 云与企业支持、认证、托管构建、私有后端加速 | 境内用户数据、厂区点云 / 高精地图、未出口源码主库 |
| SDK、文档、对象代码许可 | 具身海外集成与备件（非控制） | RWA 合约、钱包、名册 |

编译器里不要内置「一键铸币」。开源许可选 OSI 常规许可证（Apache-2.0 一类），不要自制「只能给基金 LP 用」的假开源。

### 分阶段（现在不必先设基金会）

1. **现在**：只设新加坡 HoldCo + Cheng Tech。董事会决议 + 对内 OSS 章程：对外镜像、CLA、商标由 Cheng Tech 代管，并写明第一笔机构 LP 交割前必须把 steward 职能迁到独立 CLG。先把开源和许可跑起来，不要等基金会。
2. **第一笔机构 LP 或外部贡献者超过内部提交**：独立新加坡 CLG。Pte Ltd 不能改成 CLG，必须新设再迁职能。
3. **开曼 Tech Fund**：只认购 HoldCo / Cheng Tech / UniMaker 优先股；投资备忘录写死不取得 steward 成员控制权。具身持股仍低于 25% 且无控制。
4. **永远不做**：开曼持有开源版权、特拉华当知识产权所有人、用代币当 Cheng 治理权、让基金有权关闭开源许可。

新加坡 CLG 是《公司法》下的公众担保有限公司，没有股本，成员以担保额为限。不需要先拿慈善 / IPC 身份；那是税务待遇，不是 steward 的成立条件。章程必须写：开源许可不可撤销地对外有效、成员大会不能把项目改成专有软件、解散时商标与 git 只能转给同类 steward。

## 对照 Manus：喝茶分两种，架构挡的是第二种

Manus（蝴蝶效应）2025–2026 的公开事实链是：境内做成通用 AI Agent → 总部迁新加坡、国内团队从约 120 人收到约 40 人、关停境内服务并屏蔽中国 IP → 2025-12 Meta 约 20 亿美元 acquihire（团队 + 技术进 Meta，创始人拟任 Meta 副总裁）→ 2026-01 商务部按出口管制 / 技术进出口 / 对外投资评估调查 → 2026-04-27 外商投资安全审查工作机制办公室**禁止投资、责令撤销**。公开报道还有创始人被限制出境。这是《外商投资安全审查办法》落地后 AI 领域首次公开「禁止」档，不是普通备案面谈。

监管打的不是「去新加坡开公司」，是这五件事叠在一起：

1. **洗澡式出海**：境内长成的技术，用迁址 + 关停境内 + 换新加坡壳，再卖给美国科技公司。
2. **未许可的技术出口**：能力在境内形成，实质交给境外控制人。限制出口技术目录（2023 修订）把部分 AI 自主任务规划 / 闭环执行划进限制类；向境外提供管制技术要许可证。人不走、代码走，也算出口。
3. **变相出口**：837 号令把跨境派核心技术人员、境外技术指导、培训写进对外投资监管。把研发重心搬出中国，就是这条。
4. **外资安审穿透**：买的是新加坡股权，审的是境内来源的技术、数据和团队指挥权。形式合规挡不住实质控制。
5. **把控制权交给美国大厂**：acquihire、创始人去对方任职、IP 授权进 Meta 体系。这是「技术主权」口径，不是税务口径。

### 承道合一这套架构挡什么、挡不住什么

| | Manus 路径 | 本架构 | 还会不会被叫去说明 |
|---|---|---|---|
| 境内主体 | 收缩、关停、屏蔽中国用户 | 产业母体留下，国内继续运营 | 正常年报 / 许可检查 |
| 新加坡 | 替换总部、给卖身做壳 | 许可与商业 HoldCo，有人有租有账 | ODI 实质审查会问人在哪 |
| 核心团队 | 迁出 + acquihire 进 Meta | 主研发留境内；境外是交付不是搬家 | 派驻核心人员仍可能触发变相出口，要报 |
| 控制权 | 卖给 Meta | 开曼基金少数优先股 + 赎回；美国只做销售 | 基金变成控股或卖给美科技公司 = 重走 Manus |
| 技术出口 | 未走许可就把能力交出 | 公开树、SDK、对象代码先分类再出 | **分类本身就会约谈**，这是程序 |
| 开源 | 无 | OSI 公开树 | 无偿全球扩散面比卖给一家公司更大，**必须先许可** |
| 数据 | 用户与研发外迁 | 个人信息 / 点云 / 主库留境内 | 数据出境评估会约谈 |

所以：

- **程序型喝茶躲不掉，也不该躲。** 837 安全审查、技术出口分类、数据出境评估，约谈就是正道。主动报、材料齐、境内还在运营，这是备案面谈。
- **惩罚型喝茶（调查、限制出境、禁止交易）对应的是规避。** 关停境内、团队外迁、卖给美国巨头、用新加坡清洗国籍，这套架构明文禁止。
- **开源不能当免死金牌。** 境内长成的编译器 / Agent 能力挂到公网，出口管制看的是「向外国组织或个人提供」，不是「有没有收钱」。先分类：语言规范、公开 API、非管制示例可以开；自举链敏感层、具身控制、未出口权重不能开。不准就不要挂。
- **以后最像 Manus 的三步**：HoldCo 控制权卖给美国云厂或模型厂；创始人带着编译器团队去对方任职；一边开源一边把完整自举链和训练权重放到美国云。任一步发生，前面的新加坡双核都救不了。

具身智能 + 编译器比消费级 Agent 更敏感，不是更不敏感。预判 837 安全审查和两用物项，按「会审」来建，不要按「不会问」来建。

## 1. 为什么必须切开

| 业务 | 实质 | 主要监管 | 和另外三条混在一起会怎样 |
|---|---|---|---|
| Cheng | 编译器 / 语言 / 工具链，软件 IP | 中国技术出口、两用物项、美国 EAR（软件、加密；若含受控模型权重则可能落入 4E091 一类） | 和 RWA 混：持牌金融公司被当成军用软件出口人 |
| UniMaker | 创作 / 制造软件与端侧应用 | 应用商店、个人信息、内容、出口 | 和具身混：摄像头 / 地图数据会把消费软件拖进关键基础设施审查 |
| 具身智能 | 机器人、感知、控制、现场数据 | 837 安全审查、测绘 / 数据出境、CFIUS TID、出口管制、可能的军用最终用户 | 和美国控股混：极易强制申报或禁止 |
| RWA | 把收益权 / 所有权做成代币 | **境内严禁**（银发〔2026〕42 号）；境外以境内权益为基础须发改 / 证监会 / 外汇同意；新加坡 CMS；美国证券 / 经纪 | 和 Cheng 混：境内 IT 服务也可能被认定「为 RWA 提供信息技术服务」 |

42 号文明文口径：境内开展 RWA 代币化及中介、信息技术服务，原则上禁止；境外单位不得以任何形式向境内主体提供 RWA 相关服务。所以 **RWA 的系统、客服、网站、智能合约运维都不能放在承道合一境内主体上**。

## 4. 四条业务各自怎么装

### Cheng（编译器 / 语言基础设施）

- **境内**：源码主库、自举链、国内交付、国内客户合同。
- **新加坡 Cheng Tech**：持境外许可权，对外签 SDK / 编译器许可，收许可费。
- **美国**：可设销售公司，不持核心源码控制权；对美客户交付走分类后的二进制 / 文档。
- **出口**：按物项做中国技术出口与美国 EAR 分类。编译器本身通常不是「代币」；若发行带治理权的「开发者积分」，按证券 / 虚拟货币处理，不要和编译器许可绑在一起。
- **开曼 Tech Fund**：可持 Cheng Tech 少数优先股，带赎回，不持境内承道合一股权。

### UniMaker（创作 / 制造软件）

- **境内**：国内用户、支付、内容审核、个人信息存储。
- **新加坡 UniMaker Pte**：海外商店、海外账号、海外支付。
- **数据**：国内用户数据不出境；海外用户数据不进境内生产库。两套账号体系。
- **不要**把 UniMaker 的摄像头 / 空间扫描能力接到具身机器人上共用一个法人，否则消费软件会被当成感知系统。

### 具身智能

- **境内**：研发、制造、产线、现场作业数据、高精地图 / 点云。这是 837 号令安全审查的高概率触发项（先进技术、可能的国防关联）。
- **新加坡 Embodied Pte**：海外集成、备件、非敏感软件许可。
- **美国**：默认不收购、不控股美国机器人 / 自动驾驶 / 安防公司；若必须碰美国传感器或软件，先做 CFIUS 强制申报判断，再决定用许可还是合资（中方不控）。
- **模型**：训练数据、权重留境内。出境只出许可范围内的推理接口。美国若把相关权重当成受控 AI 模型权重，新加坡公司从美国云训练或转存会踩 EAR。
- **开曼 Tech Fund** 对 Embodied 的持股建议 **低于 25% 且无控制权**，避免被写成「中国资本控制的境外机器人平台」。

### RWA（单独一条金融线）

按 2026 年 2 月 6 日八部门通知（银发〔2026〕42 号）+ 证监会公告〔2026〕1 号：

| 场景 | 是否可做 | 路径 |
|---|---|---|
| 在中国境内发 RWA 代币、做交易、做市、做钱包 | 否 | 认定非法发售代币 / 非法证券 / 非法集资 |
| 境内公司给境外 RWA 提供系统、运维、客服、智能合约 | 否 | 「信息技术服务」被点名禁止 |
| 境外主体向境内人卖 RWA | 否 | 境外不得向境内提供 RWA 服务 |
| 以**境内资产收益权**在境外发类 ABS 代币 | 仅经同意 | 实际控制人向证监会备案，发改 / 外汇联动；底层须有可预测现金流 |
| 以**境外资产**（新加坡物业、美国应收、基金份额）在新加坡代币化 | 可研 | MAS：代币化的还是资本市场产品，该持 CMS 就持 CMS；对零售另受限制 |
| 开曼基金直接「链上发行」境内工厂 / 机器人收益权 | 否（未经批） | 会被当成境内权益出境证券化 |

RWA 合规形态只保留这一种主方案：

1. 新加坡 **RWA Co** 申请或依托 CMS（证券 / CIS 交易），必要时走 RMO / 持牌平台，不自建无牌交易所。
2. 底层资产优先用 **新加坡 / 美国已经权属清晰的资产**（应收、设备租赁、持牌基金份额），不要一上来就打包境内基础设施收费权。
3. 若将来要用境内现金流做境外类 ABS 代币：先完成证监会备案和外汇路径，再让 **无境内运营职能的** 新加坡发行 SPV 发行；承道合一境内只当原始权益人，不碰代币钱包和智能合约运维。
4. 开曼 **RWA Fund** 只做 LP 资金池，认购新加坡发行的代币化产品或持有 RWA Co 股权，不直接面向中国居民募集。

Cheng 的编译器、UniMaker、机器人固件更新通道，都**不得**复用为 RWA 的链上发行或托管系统。

## 5. 开曼基金怎么「回购」或「战略持股」

这两种是不同交易，合同和监管都不同，不要混在一份 SPA 里。开曼用来回购或战略持股，只能买**新加坡 / 美国持股公司的股权或基金自身份额**，不能绕开 837 号令去买境内股权或把敏感技术装进空壳。

### 战略持股（主路径）

- 基金认购新加坡 HoldCo 或 Cheng Tech / UniMaker 的**可赎回优先股**，或普通股 + 股东协议。
- 权利用合同写死，不要用协议控制境内运营公司：信息权、一票否决限于保护性事项（负债、稀释、卖核心 IP、改数据出境）、董事席位、随售 / 拖售、ROFR。
- 估值按新加坡公司，不按境内基础设施资产包。境内资产增值通过**许可费、服务费**进 HoldCo，经独立交易和转让定价文件。
- 持股上限建议 15%–24.9%，避免被写成控制权变更触发 CFIUS / 境内安全审查。具身线再压到无控制。

### 回购（只允许下面三种）

| 类型 | 谁买谁 | 合规要点 |
|---|---|---|
| HoldCo 定向减资 / 赎回优先股 | 新加坡公司赎回基金持有的优先股 | 新加坡公司法资本维持、偿债能力声明；中国侧看是否构成利润汇回或资本回流，走经常项目或资本项目对应登记 |
| 基金 LP 份额赎回 | ELP 按 LPA 赎回 LP | 封闭期、门槛、CIMA 私募基金规则；中国 LP 赎回所得调回要有 ODI / 37 号文原路 |
| 基金受让其他股东的 HoldCo 股 | 二次交易 | 预留 ROFR；美国业务占比高时评估 CFIUS |

「回购」在合同上应写成：新加坡公司按预先公式赎回基金持有的优先股，或基金按 LPA 赎回 LP 份额。达不到 KPI、或出现合规红线（实体清单、OFAC、CFIUS 强制措施、837 安全审查否决）时，强制赎回或转让给合格买方。

### 不要做的「回购」

- 开曼或新加坡主体在未走 QFII / 沪深港通 / 回购专用账户的情况下买 A 股「自有股份」。
- 用境内资金名义借道开曼买回境内股权，规避发改 / 商务 / 外汇。
- 大股东个人境外壳公司无 37 号文登记却持有开曼 GP / HoldCo。
- 用基金回购包装大股东套现并绕过减持 / 外汇。

## 6. 两只开曼基金，不要一只混装

**Tech Fund（技术战略基金）**

- 投向：新加坡 Cheng Tech / UniMaker / Embodied 的股权。
- 工具：可赎回优先股 + 股东协议（信息权、保护性否决、合规强制赎回）。
- 美国 LP：投资政策写死——不投中国被 OISP 覆盖的半导体、量子、特定 AI 实体；具身若被认定为 covered AI，对美 LP 做单独附录或直接不接纳美国 LP。
- 「回购」= 新加坡公司按公式赎回基金持有的优先股，或基金按 LPA 赎回 LP 份额。

**RWA Fund（金融资产基金）**

- 投向：MAS 路径下的代币化产品、持牌平台份额、RWA Co 股权。
- 不投境内承道合一、不投境内基础设施收益权（除非已走证监会 1 号公告）。
- 与 Tech Fund 分托管、分银行、分董事；交叉投资要当成关联交易披露。

一只基金同时持机器人股权和 RWA 代币，会把金融牌照风险灌进出口管制主体，审查时按最严的那条打。

基金形态：封闭式策略用 **ELP + CIMA Private Funds Act 登记**。基金本身一般不做经济实质测试，但要做年度 ES Notification。GP、在开曼发生的基金管理、控股公司可能落入相关活动，要有董事、记录、外包协议。战略持股若向多名 LP 收钱并投一组公司，按基金登记，不要赌「非基金安排」豁免。

## 7. 三条流分开走

**股权流**  
境内机构 → ODI → 新加坡 HoldCo（可经香港中间层，但不能当免审层）。  
开曼 Tech Fund → 现金增资或受让 → 新加坡技术公司少数 / 战略股。  
境内运营公司股权**不**装进开曼。

**资金流**  
出海资本金：ODI 登记后从境内银行划到新加坡。  
许可费 / 实施费：新加坡 / 美国公司按合同付境内，税务局要看独立交易。  
基金投资款：LP → 开曼托管 / 账户 → 新加坡增资。  
回购款：新加坡公司可分配利润或合法减资 → 基金 → LP；中国 LP 调回走原 ODI 路径。

**技术与数据流**

```
境内 Cheng / UniMaker / 具身法人
        │  许可（可撤销）、实施服务、备件
        ▼
新加坡对应子公司 ──► 亚太/美国客户
```

- IP 所有权可留境内，出海用独家许可；违约或监管命令可收回。
- 具身现场视频、点云、厂区地图：默认不出境。
- UniMaker 用户作品：按用户协议分境内外存储。
- Cheng 源码：境外只给目标码 / 头文件 / 文档，完整自举链留境内。
- RWA：代币持有人名册、私钥、链上运维全部在新加坡持牌主体，不进境内生产网。
- 美国：EAR 管辖物项、加密件、军事 / 基础设施客户要做出口分类；不能假定「开曼持有 IP 就不算中国来源」。
- 出境只出经过分类分级、最小必要、合同 + 标准合同 / 认证 / 安全评估（个保法 / 数安法 / 网安法 / CAC）允许的接口、文档、二进制、许可对象代码。

## 8. 各国硬门槛（2026 口径）

**中国**

- 机构 ODI：发改备案 / 核准 + 商务备案 / 核准 + 外汇登记，三位一体仍在；其上叠加国务院令第 837 号《国务院关于对外投资的规定》（2026-07-01 施行）——统一框架、安全审查、事后持续监管、实质重于形式。
- 具身、编译器核心、可能的训练集群：预判安全审查。敏感领域后续境外再转让、重组也可能再审。
- RWA：42 号文境内禁；境外以境内权益为基础必须同意 / 备案（证监会 1 号公告类 ABS 代币路径）。
- 个人股东持开曼 / 新加坡 SPV：先 37 号文，再出资。
- 禁止把「先设开曼再并购」当成已出海、已合规。

**新加坡**

- HoldCo 要有本地董事 / CEO 决策记录、办公室、工资单，才能谈税务居民和优惠。
- RWA：MAS《Guide on the Tokenisation of Capital Markets Products》（2025-11-14 修订）——代币化不改变证券属性；分销要 CMS。
- 若向他人募集并管理开曼基金：评估是否构成 CMS / SFA 持牌业务，不要用「顾问协议」假持牌。
- 个人数据跨境遵守 PDPA；对中国来的数据仍要满足中国出境规则。

**美国**

- **入境**：中国控制的主体买美国业务、拿董事会、拿关键技术、靠近关键基础设施 → CFIUS。具身的激光雷达 / 相机 / 自主导航更敏感。
- **出境投资限制**：OISP（Treasury Outbound Rules，2025-01-02 生效，31 C.F.R. Part 850）约束的是**美国人投中国敏感技术**（半导体、量子、特定 AI）。FY2026 NDAA 所附 COINS Act（2025-12-18 签署）把该制度立法并扩大覆盖国家和物项，但财政部须在 2027-03-13 前出新规，此前仍执行现行 OIR。
- 开曼基金一旦接美国 LP，美国人通过基金投回中国被覆盖实体，LP / GP 都可能踩禁止或申报。投资范围必须写死：只投新加坡 HoldCo 及美国商业公司，不投境内运营公司、不投被覆盖的中国 AI / 半导体实体。
- Cheng / UniMaker 卖软件：EAR 分类。RWA 若向美国人发行：证券登记或豁免（Reg D / S），不是「链上就不算证券」。

**开曼**

- 两只 ELP 分别 CIMA 登记。
- GP 经济实质。
- 基金不做 RWA 对客发行，只做 LP 集合投资。

## 9. 合同工具（战略持股包）

新加坡 HoldCo 股东协议建议固定这些条款，管辖选新加坡法、仲裁选 SIAC：

- 持股上限（例如 15%–24.9%；具身线无控制）
- 保护性否决：超额负债、发行稀释、出售核心许可 IP、改变数据出境范围、变更主营
- 信息权：经审计账、重大诉讼、对美客户清单（可脱敏）
- 赎回：达不到 KPI 或出现合规红线时，HoldCo 按预先公式赎回基金持股
- 合规解除：出现实体清单、OFAC、CFIUS 强制措施、837 安全审查否决时，强制赎回或转让给合格买方
- 不竞争与 IP：境内背景 IP 独家许可给出海主体，许可可撤销，所有权不转移

## 10. 落地顺序（按风险）

1. 境内把四条业务分到不同法人，或至少不同事业部 + 独立账套；做数据分类、出口管制自评估、ODI 敏感行业预判。
2. 新加坡 HoldCo 实体化（人、租、银行、IP 许可合同）；先设 Cheng Tech、UniMaker；对外开源镜像由 Cheng Tech 按 steward 章程代管。
2a. 第一笔机构 LP 或外部贡献过门槛：新设新加坡 CLG，迁出开源 steward；基金认购文件写死不控制 CLG。
3. Embodied 新加坡公司后设；美国不控。美国 OpCo 只开 Cheng / UniMaker 商业，不先买受管辖标的。
4. 发改 / 商务 / 外汇走 ODI；个人股东并行 37 号文；具身与编译器核心预判安全审查。
5. Tech Fund：开曼 ELP + GP + 托管，CIMA 登记，新加坡管理人牌照或豁免意见；对 Cheng / UniMaker 战略持股、写赎回。
6. RWA：先拿 MAS 路径或与已持 CMS 的平台合作，**不要**先发境内资产代币。
7. 若监管允许境内权益出境 ABS 代币，再单独立项走证监会 1 号公告，与前六步解耦。
8. 每年：ODI 年报、外汇存量、开曼年费与 ES 通知、新加坡审计、美国如有覆盖交易的 OISP / CFIUS 年检。

先把新加坡 HoldCo 做实、把许可和 ODI 做完，再设开曼基金。基金是最后一层资本结构，不是第一层逃生门。

## 11. 红线

四条业务合写时最容易踩：

- 承道合一官网、公众号、小程序帮境外卖 RWA。
- Cheng 编译器或 UniMaker 里内置「一键铸币 / 链上确权」。
- 用厂区机器人采集的数据当 RWA 底层资产却不出境评估、不备案。
- 开曼一只基金既持机器人股权又发收益代币。
- 美国子公司既训练具身模型又托管代币钱包。
- 向境内合格投资者「远程开新加坡账户买 RWA」（仍可能被认定向境内提供服务）。
- 开曼基金持股或协议控制开源 steward，或章程允许把 Cheng 改回专有软件。
- 把唯一权威源码放在 GitHub 美国账号当事主（GitHub 只做镜像）。
- 用带治理权的代币当 Cheng 开源治理，和编译器许可绑在一起。
- 走 Manus 那条：关停境内、屏蔽中国用户、核心团队迁新加坡、再把控制权卖给美国科技公司（含 acquihire、创始人去对方任职）。
- 未做技术出口分类就把编译器 / 权重 / 具身控制栈挂上公开 git。
- 用开源或「新加坡主体」当已出海完成，跳过 ODI / 837 安全审查 / 技术出口许可。

通用红线：

- 开曼 / BVI 空壳控制境内基础设施公司（类 VIE）当作出海完成。
- 无 ODI、无 37 号文的境外持股。
- 把重要数据、个人信息、未评估源代码主库放到美国或开曼服务器「方便交付」。
- 向境内不特定对象募开曼基金份额。
- 用基金回购包装大股东套现并绕过减持 / 外汇。
- 美国 LP 资金经开曼投回中国被覆盖的半导体 / 量子 / 特定 AI 实体。
