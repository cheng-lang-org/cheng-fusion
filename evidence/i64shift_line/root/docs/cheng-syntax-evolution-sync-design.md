## 一、命题判定：一半成立，一半需推翻

### 1.1 成立的一半：分发确定性

两条性质，来源不同：
- **(a) 同 CID ⇒ 逐字节同对象**。CAS 内蕴，免费。
- **(b) 同源闭包 CID ∧ 同编译器 CID ⇒ 同产物 CID**。这是确定性编译，**不免费**——正是本战役在建的 GEN2/GEN3 原始字节固定点（`docs/cheng-plan.md:75/:722`；候选固定点已在克隆树达成但源码未冻结 ⇒ 不是发布级，`:1154`）。

(a)+(b) 合起来才是「同步」的物理地基：任何节点拿到同一对 CID，就能**重烤并对拍**，而不只是「信任分发者」。

### 1.2 需推翻的一半：封闭分发推不出「无碎片」，且与自托管自相矛盾

**先说矛盾**。自举固定点的定义是「该 CID 的编译器能从**源闭包**编译出字节相同的自己」（分布式草案 §二 L1）。要让「全网任何节点可验证」成立，验证节点必须持有源闭包 ⇒ 源必然在 CAS 中流通。若源不流通，只有持源的中心能验证，1.1 的地基退化为「信任中心」。因此 v1 里「fork 防护 ✓（拿不到基底）」**只在验证权中心化时成立**，与同一节的「全网可验证」互斥，二者只能取一。本文取全网可验证，fork 防护降级为协议性约束——这与 `docs/cheng-decentralized-compute-storage.md` A1.2 的既有立场一致：「唯一发布权 + 唯一入口，而非强行全网唯一物理副本」。

**再说碎片**。版本碎片有三个真实成因，封闭编辑器最多挡一个、且有代价：

| 碎片成因 | 封闭编辑器能防吗 |
|---|---|
| 源码 fork | 仅当验证中心化 ✓；全网可验证 ✗（源必在网上） |
| 版本时点（节点停留旧 CID） | ✗——除非网络协议拒绝旧纪元节点（强制共识切换） |
| 方言（演化语法的必然产物） | ✗——语法包是可写数据，两支语法包 = 两支方言，与分发封闭无关 |

第三条是核心张力：**可递归自改进的语法必然产生分叉候选，「全网同一语法」必然压制分叉**。两者兼得只能靠显式机制（§三），封闭买不到。

另：「不能复制代码」是协议性约束非物理约束。确定性编译不会让逆向更难：产物是源的确定性函数，且 1.2 已证源本身必须在网上。架构正确性不得押在此上。

## 二、更深一层：封闭与递归自改进的张力是治理选择

递归自改进需要**能读写语言定义的演化主体**。编辑器不暴露代码 ⇒ 演化主体收敛为控制编辑器的唯一权威 ⇒「全网同步进化」成立但机理是**中心化自动更新**，不是「全网进化」。三个选项须显式：

| 选项 | 演化主体 | 无碎片 | 演化开放性 | 备注 |
|---|---|---|---|---|
| 权威演化 | 单一主体推语法包 | ✓（强制同步） | ✗ | 即中心化自动更新 |
| AI 演化 | AI 体系（子代理/策略进化）读写语言，人类只使用 | ✓ | 对人 ✗ / 对 AI ✓ | 「AI 持有语言」；治理归属必须说清 |
| **开放演化 + 机制兜底** | 全网可提交语法包 | 靠 §三机制 | ✓ | **本方案推荐** |

## 三、推荐架构：开放演化 + CAS 锚定 + 语法纪元切换 + 编译器即迁移器

### 3.1 语法包进 CAS（数据模型）

语法包 = 不可变 CAS 对象，字段：

```
SyntaxPackage {
  cid                 // 内容根
  parent_syntax_epoch // 基于哪个 canonical 纪元
  rule_delta          // 层③ parser 规则表增量（纯数据）
  macros[]            // 层② 宏定义（可空；spec macroDecl）
  migrator_cid        // 迁移器（同语言源，见 3.3）
  eliminates[]        // 消除的债编号 D1..D16（债清单铁律：≥1 条，否则不准入）
  proofs              // 三道固定点回执 CID + 判词族面板 CID
  author_id, signature// 复用 lock 身份面（spec 1.5）/ libp2p DID（收敛蓝图 §2.2）
}
```

每支方言 = 一个可验证、可回溯、可对拍的分支。碎片之所以是碎片，恰因「无法机器判定两方言的关系」；CAS + 确定性 + `parent_syntax_epoch` 使其成为可判定的 DAG 节点——**方言不再是碎片，而是带证书的演化分支**。

### 3.2 语法纪元共识切换

- 全网按共识在**纪元点**原子切换 canonical 语法包；`syntax_epoch` 取代「版本号」成为兼容性单元。
- **拒绝的对象要精确**：网络协议拒绝的是**向当前纪元提交**的过期纪元产物/源块，不是节点本身，也不是历史。
- **历史全部保留**：每个纪元的编译器都是不可变 CAS 对象，历史产物永远可用其当纪元编译器重烤验证。「拒绝过期」= 不再接受为当前 canonical，≠ 删除。
- 时点碎片由此消解——这是封闭模型买不到的那一半。

### 3.3 编译器即迁移器

自宿主演化语法的独有优势：**旧语法 → 新语法的迁移器本身就是同语言的语法变换**（战役 2.0 宏系统产物），随语法包分发，旧代码升级由语言自身能力完成。

两条硬性质：
- **纯函数 + 确定性 + 燃料上限**。由此 `migrate(S)` 的 CID 是确定的 ⇒ 任何旧纪元源都有一个 canonical 的迁移后孪生，**旧内容永不搁浅**，跨纪元交换源块是良定义的（收方按需迁移，结果全网一致）。
- **验收不能写「字节固定点对拍」**——迁移按定义改变源字节。正确判据是**产物与语义不变**：设 S 在纪元 E 编译器下产物 P，`migrate(S)` 在 E+1 编译器下产物 P′，则 `P ≡ P′` 按两半判据（`.primary.o` 逐字节 ∧ exe 差异 ⊆ 承诺块两摘要 + 末 32 B）∧ 语义锚 (rc, stdout sha256) 相同 ∧ 234 闭包判词族零回归。三件仪器已在库，零新仪器。

### 3.4 纪元内自由、纪元间收敛（准入是机械的，收敛是治理的）

- **纪元内**：方言实验完全自由，CAS 保证可验证。
- **准入（机械，任何节点可复算）**：三道固定点 PASS ∧ `eliminates` 非空且每条特性绑定 ≥1 条债编号 ∧ 迁移器满足 3.3 两条性质 ∧ 宏展开产物过 D3 canonical 名身份（不新增键域，债清单层②准入）。不满足 ⇒ 不进入候选，无治理可谈。
- **收敛（治理，可插拔）**：多支通过准入的候选竞争同一纪元的 canonical 位——权威裁定 / 社区投票 / 基准评分，本文不定。

## 四、生命周期与失败模式

```
提交(签名) → 机械准入(3.4) → 候选期(纪元内方言) → 收敛(治理) → 纪元点激活
   → 惰性迁移(收方按读迁移, CID 确定) → 旧纪元转只读历史
```

| 失败模式 | 机制如何处置 | 残余 |
|---|---|---|
| 节点滞留旧纪元 | 其新提交被拒；其历史产物仍可验证；`migrate` 确定 ⇒ 随时可无损接入 | 无 |
| 两支候选竞争 | DAG 上两个可判定分支；收敛后败方仍是合法历史分支 | 无（不是碎片，是分支） |
| 迁移器有缺陷 | 3.3 验收在准入期拦截（两半判据 + 语义锚 + 判词族）；漏网 = 三道固定点失效，同战役其他缺陷一样按 fail-closed 处理 | 与编译器缺陷同级 |
| 宏/迁移器不终止或有副作用 | 纯函数 + 燃料上限，超限 = 准入 FAIL | 无 |
| 恶意语法包 | 签名 + 机械准入；字节错 ⇒ CID 不匹配即拒；「字节对语义错」在确定性前提下不存在 | 社会工程（治理层） |
| **网络主权分裂**（一部分节点拒绝共识结果，另立纪元） | **机制不消除**。只能保证两边互为可判定、可迁移的分支 | **唯一真残余** |

⇒ 诚实的命题修正：本架构消除的是**不可判定的碎片**与**无迁移路径的碎片**，不是「碎片」这个词的全部——主权分裂是治理事实，任何技术都不消除，只能让它可对拍、可回归。

## 五、与封闭模型的对比账

| 维度 | 封闭编辑器模型 | 开放 + CAS + 语法纪元模型 |
|---|---|---|
| fork 防护 | 仅验证中心化时 ✓ | ✓（fork 有身份、可判定，无需隐藏） |
| 全网可验证 | ✗（源不流通 ⇒ 只能信任中心） | ✓（源与编译器同在 CAS） |
| 时点碎片 | ✗（除非强制升级） | ✓（纪元拒绝 + 确定性迁移） |
| 方言碎片 | ✗（语法包必然分叉） | ✓（可判定分支 + 纪元收敛） |
| 演化开放性 | ✗（单一权威） | ✓（全网可提交，机械准入） |
| 逆向防护 | 摩擦级（非绝对） | 同级（与封闭无关） |
| 演化速度 | 权威节奏 | 纪元节奏（竞争 + 收敛） |
| 主权分裂 | 不适用（无人能分裂） | 残余（§四最后一行） |

封闭模型买到的只有「验证中心化下的 fork 防护」，代价是演化开放性和全网可验证；开放模型用三机制覆盖三成因，残余只剩主权分裂。

## 七、一句话总纲

**「无碎片」的正确技术来源是语法纪元共识 + 确定性迁移器 + CAS 可验证性，不是代码不可见**——后者只在验证中心化时买到 fork 防护，代价是演化开放性与全网可验证，且买不到时点碎片与方言碎片的免疫；开放模型把碎片变成可判定、可迁移的分支，唯一残余是治理层的主权分裂。
