# MICRODUCK 1:1 仿真保真度终验评估

日期：2026-09-15。性质：纯分析（不改代码）。任务：把 CEM 调优参数与官方 MICRODUCK 策略做对照，给出"1:1 仿真保真度"结论与可行收敛路线。

证据等级标注：**官方**（官方 README/模型卡/MJCF/文档，高）、**实测**（我方探针/调参 receipt，高）、**推断**（中）、**文献**（低）。

---

## 0. 结论先行

1. **物理保真度：现象级已达标，策略级未达标。** 我方引擎已精确复现纯滚（5/7v₀ 解析精确）、库仑摩擦（μ·jn 修复后足底滑动精确 0）、负载滚动阻力、球上持续静态平衡（真参数机器鸭 9216 tick/16s 站满，漂移 464mm<500mm）。官方 Demo 的"球上动态平衡"= 持续平衡 **+ 速度指令跟踪**（±0.15m/s 前进/±0.10m/s 侧向/±0.5rad/s 偏航，20s/60s 存活 98.86%/97.01%），我方系统当前只能站、不能按指令动。
2. **差距主因是策略表达力，不是物理保真度。** 官方是 61 维本体感知 → LSTM(256) → 14 维动作 @50Hz（约 62.4 万参数的闭环策略）；我方 CEM 调的是 **2 个活标量**（trimRate/trimRange，6 个增益维已被证明逐位惰性）。14 vs 2 个动作自由度、有记忆 vs 无记忆、48 维速度型观测 vs 位置型 CoM 误差（N7 实测：位置环对 0.35m/s 球速逃逸事件全盲）。
3. **一个引擎级硬缺口仍在**：位置级库仑锥的每步剪切权限 ~24mm/s（bound=0.6×穿透≈0.17mm/步）vs 球上逃逸事件 350+mm/s（**15× 缺口**，N7 定谳）——力矩/速度级执行器原语落地前，任何参数增益都无法改变系统角动量。
4. **收敛路线推荐 (a)+(b) 组合**：力矩电机原语（M1-M5 设计稿就绪，估 13-20 人日）补剪切权限，速度项反馈+CEM 目标运动通道扩展（估 8-13 人日）补策略带宽。纯环境参数路线 (c) 已有定谳天花板（caseI：Crr≤0.15 只能延缓不能根治），只配当辅助。

## 1. 官方资料要点（全部官方等级）

### 1.1 pollen-robotics/microduck（机器鸭本体）
- ~25cm / ~800g 双足鸭，15 个舵机，RK3566，**50Hz 控制环**驱动 15 舵机（robotd 持有）。（官方 README）
- 策略在 microduck_rl 训练（MuJoCo+PPO+域随机化），ONNX 导出上机。

### 1.2 pollen-robotics/microduck_rl（训练栈）
- **mjlab = MuJoCo Warp + rsl_rl**，4096 并行环境，1-2 小时得可用步态；策略 **50Hz** 训练/部署。（官方 README）
- **观测 61 维**：48 维本体感知 + 指令 twist(3)+head_pose(4)+body_pose(6)，未用指令槽补零（策略热切换）。（官方 README）
- **动作 14 维**：左腿 5（hip_yaw/roll/pitch、knee、ankle）+ 颈 4 + 右腿 5；ONNX 校验 [1,61]→[1,14]；被动关节（滚轮/backlash 铰）正则排除。（官方 README）
- **执行器模型 BAM M6**（Dynamixel XL330）：电压控制律、反电动势、Coulomb/Stribeck/负载相关摩擦；`--no-bam` 退回普通 PD。官方原话：**"在这个尺度上，执行器保真度就是 sim2real gap 的大头"**。（官方 README）
- **backlash**：每个主任务有 `-Backlash` 孪生环境，14 关节各串 ±1° 齿隙被动铰，编码器在输出侧——观测与动作都穿过齿隙。（官方 README）
- **域随机化**：电池电压、负载压降、指令延迟、摩擦幅值，逐环境随机。（官方 README）
- 奖励项/权重、PPO 超参、物理时间步、接触参数**未在 README 披露**（在 env 配置与 AGENTS.md/tasks/mdp.py 里）。（官方 README 的否定性事实）
- MJCF 变体：robot_walk.xml 砍掉躯干/头碰撞（"摔倒很便宜"）；无 `<geom>`、无 armature/damping/frictionloss（MuJoCo 默认 0）——后者为我方 M6 逐项核对（实测）。

### 1.3 HannesVonEssen/microduck-basketball（对标 Demo 的策略）
- **任务**：microduck 站自由滚动的 **7 号篮球**上，纯本体感知跟随速度指令；**观测无球状态**（actor 对球全盲；特权 critic 训练期可见球）。（官方模型卡）
- **结构**：单层 **LSTM(256)** → ELU MLP(512,256,128) → 14 动作，actor ~62.4 万参数；ONNX 输入 obs[1,61]+h/c[1,1,256]，输出动作+新 h/c，**50Hz**。（官方模型卡）
- **观测 61 维**：陀螺仪(3)+投影重力(3)+关节位置(14)+关节速度(14)+前动作(14)+速度指令(3)+补零(10)。（官方模型卡）
- **奖励**：模型卡只记 action-rate 罚 -0.2（惩罚平方动作变化），完整奖励未列。（官方模型卡）
- **起点**：机器人被支撑在球顶直立释放；**策略不会上球、不会从地面恢复**。（官方模型卡）
- **扰动课程**：评测重置时基座水平速度 ±0.09m/s、每 0.5-1s 一次；无角扰动。（官方模型卡）
- **指令范围**：训练 ±0.15m/s 前 / ±0.10m/s 侧 / ±0.50rad/s 偏航；压力测试 ±0.30/±0.20m/s、±1.0rad/s；[0,0,0]=原地平衡。（官方模型卡）
- **续训配方**：LR 固定 2e-5、10s 回合、4096 环境、500 迭代、push 间隔 1.5-3s、seed 42、无蒸馏无运行时动作滤波。（官方模型卡）
- **评测（3072 次）**：盲 LSTM b11 存活 20s/60s = **98.86%/97.01%**，偏航 MAE 1.26rad/s，动作变化 RMS 0.234；球状态 MLP 对照 99.67%/99.12%。（官方模型卡）
- **未披露**：MuJoCo 时间步、solver、摩擦、球质量/半径。（官方模型卡的否定性事实）

### 1.4 MuJoCo 接触模型默认参数（对照基准）
- 默认 **timestep=0.002s（500Hz）**、solver=**Newton**、iterations=100、tolerance=1e-8、cone=**pyramidal（椭圆锥为选项）**、impratio=1、integrator=Euler。（官方文档，mujoco.readthedocs.io XML Reference / Computation）
- 篮球环境的具体步长/solver 覆盖未披露；mjlab 人形类任务常用 0.002-0.005s 物理步 + 50Hz 策略（20-40 倍 decimation）——**推断（中）**。

## 4. 保真度结论：能复现 vs 不能复现

### 已复现（实测，高）
- **纯滚**：5/7v₀ 解析精确，ωx·r=v 逐位验证（rigid_ball_probe / findings B1）。
- **库仑摩擦**：μ·jn 预算修复（F1）后足底滑动精确 0mm/s，抓地力恢复 20 倍缺口。
- **滚阻**：骑乘载荷滚动阻力（M-a，Crr=0.03，load_N≈m·g 定量正确，空载零影响）；负载球衰减 205.8mm/s 精确吻合 0.5−Crr·g·t。
- **球上静态平衡**：质点人形 14300 tick 不倒（真实规格小球漂移 89.7mm）；真参数 15 链/14 关节机器鸭 **9216 tick 站满**、漂移 464mm<500mm、零拒绝——官方 Demo 的"joint control/free ball"画面任务级复刻（2026-09-15《MICRODUCK BALL BALANCE II》）。
- **约束投影规范漂移**：俯仰棘轮根因定谳+gauge 修复（T-D），双足站立 A/B/D 全 GREEN。

### 不能复现（差距定谳）
1. **球上动态平衡（指令跟随）**——官方 20s/60s 存活 98.86%/97.01% 含 ±0.09m/s 周期推扰 + 速度指令跟踪；我方定格在"站住"（漂移靠环境汇 Crr 压制，caseI 定谳：Crr≤0.15 共模滚走只从 ~5m 压到 ~4.4m，环境杠杆只能延缓不能根治）。
2. **足-球剪切权限（N7 定谳的引擎级成因，15× 缺口）**：位置级库仑锥 bound=0.6×穿透≈0.17mm/步 → 每步剪切权限 ~**24mm/s** vs 球速逃逸事件 **350+mm/s**——"任何增益无法改变系统角动量"。F1 的 μ·jn 修复解决的是地面足摩擦钳真值；球上锥界的每步位移预算结构性上限仍在。这是力矩/速度级执行器缺位的直接后果（官方 BAM+力矩级 PD+RL 解决的正是这个）。
3. **速度型反馈通路**：N7 ①——位置环对速度型逃逸全盲（倒前 CoM 误差仅 5-25mm，杀手是 0.35m/s 球速事件）；N7 三杠杆拆跑 66→237 tick，方向正确量级差一个数量级（threshold=500）。
4. **执行器保真**：无齿隙、无 Stribeck、无电压衰减（官方 BAM M6+backlash+电压 sag 全套）。在 0.74kg 尺度，官方自认这是 sim2real gap 大头；对纯仿真内评测影响次级，但对"1:1 物理保真"的宣称是实缺口。
5. **训练基础设施**：MuJoCo Warp 可微+GPU 4096 环境 vs 我方 240s/episode 串行 CEM（contacts3d 模块级骑乘载荷表强制串行，M-b 教训）；无梯度、无并行、样本预算差 6 个数量级。

## 5. 可行收敛路线（核心产出）

### 路线 (a)：力矩/速度级执行器原语 + CEM 重调 —— 引擎补权限
- **内容**：落地 docs/torque-motor-design.md 的 M1-M5（capsule 刚体基座→接触摩擦出扭矩→混合腿→铰链角伺服双帽→一腿摆动，~1800 行含 ~900 行探针，5 个独立可验收 PR 粒度，设计稿已自足到"不看代码可开工"）；关键差异点：在速度级末段（physics3dBallRollingContact 同层）显式加 τ=τmax 钳制的力矩冲量通道，使足-球剪切不再受位置锥每步位移预算约束——直接拔掉 N7 的 24 vs 350mm/s 结构上限。随后 CEM 在力矩增益/目标运动通道重调。
- **工作量**：M1-M5 编码+探针 ~**10-15 人日**（设计稿行数量级已给：总计 ~1800 行）；球上 CEM 重调协议扩展 ~**3-5 人日**（每 episode ~240s，一轮调参 ≤25 分钟墙限内，按 M-b 串行纪律）。
- **风险**：M2 capsule 摩擦出扭矩的锥界换算数值需实验标定（设计稿已标"最大不确定块"）；M4 的 96 扫伺服带宽若不足需启用 (a) 冲量对后备——其能量泵风险要靠"冲量后复算门禁残差"护栏；力矩级执行器让系统欠阻尼化，控制律需重调（可由 (b) 承接）。

### 路线 (b)：质点/刚体系速度项反馈 + 目标运动通道深度强化 —— 控制补带宽（N7 杠杆全开）
- **内容**：① 速度项进环（N7 已列档：upY、ė——球速/CoM 速度进反馈，补位置环盲区）；② 接触前伺服静默窗（消除下落段 4° 前倾种子）；③ 躯干 kAng 重调（128 实测存活 70→59 恶化，需反向修）；④ trim 通道族扩展（俯仰 caseK/侧向 roll caseL 已交付，扩到髋 roll/yaw 组）作 CEM 活维；⑤ 全部动 N1 defaults verbatim 调参面，探针门控拆跑（N7 拆跑纪律：组门控避开 80 分钟墙限）。
- **工作量**：①+②+③ ~**5-8 人日**（每杠杆一轮组门控拆跑+定谳）；④ ~**3-5 人日**。
- **风险**：N7 拆跑已证三杠杆"方向正确、量级差 10×"（66→237 vs 门槛 500）——在 M-a/Q2 环境跃升（基线 66→810→9216）后杠杆效能需重标定；**天花板明确**：静态参数 CEM+手写反馈律表达不出 14 维时变策略，本路线预期止步"鲁棒站立+小幅指令响应"，达不到官方 LSTM 的指令跟随水平。要与 (a) 组合才能吃满。
- **纯 RL 路线说明（不单列）**：官方同款需 PPO×4096 环境；我方 episode ~240s+强制串行+无梯度，先要 per-episode 世界隔离+episode 提速 2-3 个数量级（缠结态 CsgSqrtStep 爆炸已归性能战役），估 **15-30 人日基建**后训练才可行——列为 (a)(b) 之后的远期选项，非本期。

### 路线 (c)：球侧环境参数继续放宽 —— 环境汇加码（辅助）
- **内容**：Crr 大幅提权（0.3+ 量级，需验证不引发 solver 病理）+ 载荷到 load 估计的完整耦合查漏（jn 份额 2fc2c965d 已落地，动态时段 +79% 耦合实证）。
- **工作量**：**2-3 人日**（caseI 同款 12 格矩阵扩 Crr 档）。
- **风险/天花板（已定谳）**：caseI——Crr 0.15 双单调压漂移但**饱和**（~5m→~4.4m），"环境杠杆只能延缓不能根治"；Crr 0.3 超出真实篮球-地板带（0.01-0.05）5 倍，作为"1:1 保真"口径反而失真。**只配作 (a)/(b) 的调参期辅助，不构成独立达标路线。**

### 推荐组合与里程碑
**(a) 前段（M1-M4，拔剪切上限）→ (b) 全量（速度环+trim 族，CEM 活维扩容）→ 复测球上存活/指令响应 → 视缺口决定 M5+力矩 CEM 或立项 RL 基建。** 合计 **~23-38 人日**到"官方 Demo 同款球上动态平衡"的工程等价物（鲁棒站立+速度指令粗跟随）；要官方级 97%/60s 存活指标， realistically 还需 RL 基建那一档。
