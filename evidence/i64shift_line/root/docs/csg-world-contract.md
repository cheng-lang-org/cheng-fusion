# CSG 世界合同（A2 冻结）

日期：2026-09-06。本文件是 [开发计划](superpowers/plans/2026-09-06-csg-semantic-physical-world-video.md) A2 交付的数值与资产合同。数字在测试前冻结；失败后未经变更提案不得放宽。求解方法决策见 [solver-decision](campaigns/2026-09-06-csg-semantic-physical-world-video/solver-decision.md)，资产范围见 [assets](campaigns/2026-09-06-csg-semantic-physical-world-video/assets.md)。

## 1. 单位、坐标与数值

- 单位：米、千克、秒、弧度。右手坐标系，Z 向上。
- 数值：物理与渲染权威求解使用 `float64`，固定计算顺序，禁 NaN/Inf（违反即 hard-fail 拒绝提交该步）。三角/开方使用 `std/math` 纯 Cheng 确定性实现（Taylor/牛顿迭代），同一冻结构建字节可重现。
- 重力：`g = 9.80665 m/s²`，方向 −Z。空气阻力：首期关闭（验收矩阵要求支撑解除实验关闭空气阻力）。
- 数值 profile：darwin/arm64、stage3 纯 cheng 编译器、`std/math` 多项式常数冻结于源码；相同冻结构建状态字节一致。

## 2. 时间

| 量 | 冻结值 |
|---|---|
| 物理步率 | 240 Hz，`int64` tick，dt = 1/240 s |
| 视频帧率 | 24 fps，每帧 10 物理步 |
| 音频采样率 | 48 kHz，每物理步 200 样本/声道 |
| 10 秒片长 | 2400 物理步、240 视频帧、每声道 480000 有效样本 |
| 区间 | `[0, 10s)`；终点状态可保存，不多导出一帧 |
| 事件落点 | tick→帧 = tick/10 向下取整；tick→样本 = tick×200；整除无累计截断误差 |

音频 AAC 编码预填充/尾部填充记录进容器时间映射，验收按有效区间裁定。

## 3. 身份与引用

- 实体身份 = 世界实例身份（producer 分配的 int64）＋分配时记录的实体身份（int32，从 1 递增）。显示名称可改，位姿变化不改身份。
- 运行引用 = `slot:int32` ＋ `entityId:int32` ＋ `generation:int32`。槽复用 generation+1；代际溢出（wrap 到 0）显式拒绝该引用；陈旧引用（generation 不匹配）拒绝并记事件。
- 骨架对应：语义身体部件、动力学刚体、蒙皮骨骼由同一对应表（部件枚举→刚体索引→骨骼索引）绑定，禁止按名称或空间邻近配对。

## 4. 求解方法（首期冻结）

- 半隐式欧拉积分：`v += (F/m)·dt; x += v·dt`，固定列序（slot 0..count-1）。
- 绳索：逐约束顺序投影（XPBD 风格 position-based distance constraint，刚度 1，32 迭代/步，固定列序），两端点按逆质量加权。
- 接触：地面平面 + AABB 脚点单边接触；法向位置修正 + 法向速度归零（恢复系数 0）+ 库仑摩擦（切向速度削减，μ 冻结于场景事实）。
- 收敛/失败：单步位置修正残差 > 10mm 或检测 NaN/Inf → 拒绝提交该步（物理时间不推进，记失败事件）。
- 误差预算：自由落体解析对拍 ≤1cm；抓牢状态抓握误差 ≤1cm；可见穿透 ≤5mm。

## 5. 动作与控制

- 控制器只施加有上限、有来源记录的力/位置目标；动力学决定位姿。IK 结果不直接覆盖权威身体。
- 抓握 = 手-锚点距离 ≤1cm 且绳索张力通路存在 → 「抓牢」由接触/承载条件推出，不是日志状态。
- 动作失败（不可达、被抓物移走、力不足）记事件，世界继续按物理推进。

## 6. 场景（十秒片）

一个角色（质量 70kg，来自版本化资产事实）、一根绳索（质量 2kg，8 节点距离约束链）、一面岩壁（静态 AABB，蹬踏面 Z 向摩擦 μ=0.8）。剧本：两次交替抓握 + 一次明确蹬踏 + 质心净上升 ≥0.5m。三机位引用同一模拟状态。

## 7. 渲染与媒体

- 渲染：CPU 流式光栅（正交/透视投影、z-buffer、Lambert 材质＋平行光），读取只读已提交世界状态；输出 1280×720 PPM 帧流。三机位同状态分别出帧。
- 音频：48kHz 单声道 PCM 混音（事件驱动：蹬踏声、旁白占位静音段）；首期交付 WAV；MP4/H.264/AAC 系统编码走 Darwin provider，未接线前如实标注不支持。
- 媒体验收：帧数 240、时长 10.0s、事件落点 ≤1 视频帧误差。
